Курс: PHP

Повний вступ у PHP для початківця: від базового синтаксису до форм, сесій і роботи з базою даних.

🎯 Для кого цей курс?

Цей курс створений для початківців, які вже бачили HTML/CSS і хочуть зрозуміти, як працює серверна частина сайту. PHP дозволяє не просто показувати сторінку, а обробляти дані, працювати з формами, авторизацією, базами даних і будувати повноцінну логіку для веб-застосунків.

Після проходження курсу ти зможеш:

  • розуміти, як запускається PHP-код на сервері;
  • створювати змінні, умови, цикли, функції і масиви;
  • обробляти HTML-форми через GET і POST;
  • працювати з сесіями та cookies на базовому рівні;
  • підключатися до MySQL і виконувати запити;
  • створювати прості динамічні сторінки та невеликі веб-проєкти.
Головна мета курсу: дати тобі не просто окремі PHP-команди, а нормальну базу для створення перших серверних частин сайтів.

📜 Історія та Призначення

PHP — це серверна мова програмування, яка з’явилася в 1995 році. Спочатку вона створювалася як інструмент для побудови динамічних веб-сторінок, а з часом перетворилась на повноцінну мову для веб-розробки.

Простими словами:
— HTML показує, що бачить користувач
— CSS визначає, як це виглядає
— JavaScript додає логіку в браузері
— PHP виконує логіку на сервері

Де використовується PHP?

  • Сайти та блоги: WordPress та інші CMS.
  • Форми та авторизація: реєстрація, логін, кабінет користувача.
  • Робота з базами даних: користувачі, товари, замовлення, коментарі.
  • Веб-застосунки: адмін-панелі, особисті кабінети, внутрішні системи.
Важливо: PHP виконується на сервері, а не в браузері. Користувач не бачить сам PHP-код, він бачить лише результат його роботи.

📂 1. Як працює PHP

PHP-код виконується на сервері. Це означає, що коли користувач відкриває сторінку, сервер спочатку обробляє PHP, а вже потім відправляє в браузер готовий HTML.

1.1 Найпростіший PHP-код

<?php echo "Привіт, світ!"; ?>

Тут:
<?php — відкриття PHP-коду
echo — виведення інформації
?> — закриття PHP-коду

1.2 PHP всередині HTML

PHP можна вставляти прямо в HTML-сторінку.

<h1> <?php echo "Мій сайт"; ?> </h1>

Після виконання сервер підставить текст у HTML, і користувач побачить готовий заголовок.

Пам’ятай: щоб PHP працював, файл має мати розширення .php, а відкривати його треба через сервер, а не просто подвійним кліком по файлу.

🔧 2. Змінні, типи даних та виведення

У PHP змінні потрібні для зберігання даних: тексту, чисел, логічних значень, масивів тощо.

2.1 Створення змінних

Усі змінні в PHP починаються зі знака $.

<?php $name = "Віталік"; $age = 18; $isStudent = true; ?>

2.2 Основні типи даних

  • string — текст
  • int — цілі числа
  • float — дробові числа
  • bool — true або false
  • array — масиви

2.3 Виведення через echo

<?php $name = "Віталік"; echo $name; ?>

2.4 Об’єднання тексту

У PHP для об’єднання рядків використовується крапка ..

<?php $name = "Віталік"; $age = 18; echo "Мене звати " . $name . ", мені " . $age . " років."; ?>
Практика:
  • створи змінні для імені, віку та міста;
  • виведи їх через echo;
  • склади одне повідомлення з кількох змінних.

📊 3. Оператори: арифметичні, порівняння та логіка

Оператори дозволяють PHP виконувати обчислення, порівнювати значення та перевіряти логічні умови.

3.1 Арифметичні оператори

<?php $a = 10; $b = 3; echo $a + $b; echo "<br>"; echo $a - $b; echo "<br>"; echo $a * $b; echo "<br>"; echo $a / $b; echo "<br>"; echo $a % $b; ?>

3.2 Оператори порівняння

<?php $age = 18; var_dump($age == 18); var_dump($age > 16); var_dump($age < 10); ?>

var_dump() зручно показує значення і його тип, тому для навчання це корисно.

3.3 Логічні оператори

<?php $age = 20; $hasMoney = true; $canBuy = ($age >= 18) && $hasMoney; var_dump($canBuy); ?>

🔄 4. Умови: if, elseif, else

Умови потрібні для того, щоб програма могла приймати рішення. Саме завдяки ним PHP-код може поводитися по-різному залежно від значень змінних або даних користувача.

4.1 Базовий приклад

<?php $age = 18; if ($age >= 18) { echo "Повнолітній"; } else { echo "Неповнолітній"; } ?>

4.2 Кілька варіантів через elseif

<?php $score = 85; if ($score >= 90) { echo "Відмінно!"; } elseif ($score >= 70) { echo "Добре!"; } else { echo "Потрібно підтягнути знання."; } ?>

Тут програма перевіряє оцінку і вибирає, який текст показати.

Практика:
  • перевірити, чи людина повнолітня;
  • знайти більше з двох чисел;
  • перевірити, чи число парне.

🔁 5. Цикли: for, while, foreach

Цикли потрібні для того, щоб повторювати один і той самий код багато разів. Без них довелося б вручну писати одне і те саме знову і знову.

5.1 Цикл for

<?php for ($i = 1; $i <= 5; $i++) { echo $i . "<br>"; } ?>

5.2 Цикл while

<?php $energy = 3; while ($energy > 0) { echo "Енергія: " . $energy . "<br>"; $energy--; } ?>

5.3 Цикл foreach

foreach дуже зручний для роботи з масивами.

<?php $names = ["Іван", "Марія", "Олег"]; foreach ($names as $name) { echo $name . "<br>"; } ?>
Порада: для масивів у PHP дуже часто найзручніше використовувати саме foreach.

🗃 6. Масиви

Масив — це змінна, яка може зберігати одразу багато значень. У PHP масиви дуже важливі, бо через них часто передаються дані форм, списки товарів, користувачів, меню та багато іншого.

6.1 Звичайний масив

<?php $numbers = [10, 20, 30, 40, 50]; echo $numbers[0]; echo "<br>"; echo $numbers[2]; ?>

6.2 Асоціативний масив

У PHP часто використовують асоціативні масиви, де замість індексів є ключі.

<?php $user = [ "name" => "Віталік", "age" => 18, "city" => "Львів" ]; echo $user["name"]; ?>

6.3 Перебір масиву

<?php $users = ["Іван", "Марія", "Олег"]; foreach ($users as $user) { echo $user . "<br>"; } ?>
Практика:
  • створи масив із 5 чисел;
  • виведи всі елементи;
  • створи асоціативний масив користувача;
  • виведи ім’я та вік через ключі.

📦 7. Функції

Функції потрібні для того, щоб не дублювати один і той самий код. Один раз написав логіку — потім викликаєш її скільки треба.

7.1 Проста функція

<?php function sayHi() { echo "Привіт!"; } sayHi(); ?>

7.2 Функція з параметрами

<?php function add($a, $b) { return $a + $b; } $result = add(5, 7); echo $result; ?>

7.3 Функція з рядком

<?php function greet($name) { return "Привіт, " . $name; } echo greet("Віталік"); ?>
Пам’ятай: хороша функція зазвичай робить одну конкретну задачу.

📝 8. Робота з формами: GET і POST

Одна з найважливіших тем у PHP — це обробка форм. Саме через форми користувач вводить логін, пароль, ім’я, коментар, email та інші дані.

8.1 Форма з методом POST

<form method="post"> <input type="text" name="username"> <button type="submit">OK</button> </form>

8.2 Отримання значення з POST

<?php if (isset($_POST["username"])) { echo $_POST["username"]; } ?>

$_POST — це масив, у якому PHP зберігає дані, відправлені через POST.

8.3 GET

Метод GET передає дані через адресний рядок.

<form method="get"> <input type="text" name="city"> <button type="submit">Надіслати</button> </form> <?php if (isset($_GET["city"])) { echo $_GET["city"]; } ?>

8.4 Різниця між GET і POST

  • GET — дані видно в URL
  • POST — дані передаються приховано від адресного рядка
Порада: для логіну, паролю, реєстрації та інших важливих форм зазвичай використовують саме POST.

💬 9. Робота з рядками та перевірка даних

Після отримання даних з форми дуже часто треба їх перевірити або обробити.

9.1 Перевірка, чи поле не пусте

<?php if (!empty($_POST["username"])) { echo "Поле заповнене"; } else { echo "Поле пусте"; } ?>

9.2 Видалення зайвих пробілів

<?php $name = trim($_POST["username"]); echo $name; ?>

9.3 Довжина рядка

<?php $password = "123456"; echo strlen($password); ?>

Так можна, наприклад, перевіряти мінімальну довжину пароля.

🔒 10. Сесії та cookies

Якщо треба запам’ятати користувача між сторінками, використовують сесії або cookies.

10.1 Сесія

<?php session_start(); $_SESSION["username"] = "Віталік"; echo $_SESSION["username"]; ?>

Сесія зберігає дані на сервері і часто використовується для авторизації.

10.2 Cookie

<?php setcookie("user", "Віталік", time() + 3600); ?>

Cookie зберігаються в браузері користувача.

Пам’ятай: перед роботою з $_SESSION потрібно викликати session_start().

💻 11. Підключення до MySQL

Одне з найважливіших застосувань PHP — це робота з базами даних. Найчастіше PHP використовують разом із MySQL.

11.1 Підключення через mysqli

<?php $conn = new mysqli("localhost", "root", "", "test"); if ($conn->connect_error) { die("Помилка підключення"); } echo "Підключено успішно"; ?>

Тут:
localhost — сервер
root — користувач
порожній рядок — пароль
test — назва бази даних

Увага: у реальних проєктах логін, пароль і налаштування бази краще виносити окремо, а не тримати прямо в коді сторінки.

🔍 12. Отримання даних із бази

Після підключення до бази можна виконувати SQL-запити і виводити результат на сторінку.

12.1 SELECT через PHP

<?php $conn = new mysqli("localhost", "root", "", "test"); $result = $conn->query("SELECT * FROM users"); while ($row = $result->fetch_assoc()) { echo $row["name"] . "<br>"; } ?>

Тут ми:
— підключилися до бази
— виконали SQL-запит
— по черзі вивели всі імена з таблиці users

12.2 Додавання запису

<?php $conn = new mysqli("localhost", "root", "", "test"); $sql = "INSERT INTO users (name, age) VALUES ('Іван', 20)"; $conn->query($sql); ?>

Так PHP може не тільки читати, а й додавати дані в MySQL.

⚠ 13. Типові помилки новачків

  • Забутий знак $ перед змінною.
  • Плутанина між лапками і синтаксисом PHP.
  • Спроба відкрити PHP-файл без сервера — код не виконається правильно.
  • Немає перевірки isset() перед використанням $_POST або $_GET.
  • Проблеми з підключенням до MySQL — неправильна назва бази, логін або пароль.
  • Небезпечна робота з SQL — без перевірки та захисту можна отримати проблеми з безпекою.
Порада: у PHP дуже важливо не просто “щоб працювало”, а ще й перевіряти дані, які приходять від користувача.
