Курс: Java

Повний вступ у Java для початківця: від базового синтаксису до перших об’єктно-орієнтованих програм.

🎯 Для кого цей курс?

Цей курс створений для початківців, які хочуть вивчити Java з нуля. Матеріал побудований так, щоб людина поступово зрозуміла синтаксис, навчилась працювати зі змінними, умовами, циклами, методами та отримала базу для переходу до ООП.

Після проходження курсу ти зможеш:

  • розуміти, як влаштована програма на Java;
  • створювати прості консольні програми;
  • працювати зі змінними, умовами, циклами та методами;
  • використовувати рядки, масиви та списки;
  • розуміти основи класів, об’єктів та ООП.
Головна мета курсу: не просто показати окремі шматки коду, а дати тобі нормальну стартову базу, після якої ти вже зможеш самостійно писати прості програми на Java.

📜 Історія та Призначення

Java була розроблена Джеймсом Гослінгом та командою Sun Microsystems і офіційно представлена у 1995 році. Однією з головних ідей мови став принцип "Write once, run anywhere", тобто програму можна написати один раз і запускати на різних системах завдяки JVM — Java Virtual Machine.

Де сьогодні використовують Java?

  • Корпоративні системи: банки, великі сервіси, бізнес-платформи.
  • Серверна розробка: бекенд, API, мікросервіси, веб-платформи.
  • Android-розробка: Java довгий час була основною мовою для Android.
  • Освіта: Java часто використовують для вивчення ООП та алгоритмів.
  • Великі дані: частина екосистеми Hadoop та інших систем обробки даних.
Важливо: Java відома своєю стабільністю, строгістю та хорошою структурою коду. Через це вона дуже популярна для великих проєктів і добре підходить для навчання об’єктно-орієнтованого мислення.

📂 1. Вступ: Як налаштувати все для роботи

Щоб працювати з Java, тобі потрібен JDK — Java Development Kit. Саме він містить компілятор і все необхідне для створення програм. Для написання коду найзручніше використовувати IDE, наприклад IntelliJ IDEA або Eclipse.

1. Встановлення JDK: встанови Java Development Kit на комп’ютер.
2. Перевірка: у терміналі можна перевірити Java через java -version і javac -version.
3. Вибір IDE: для новачка часто найзручніше IntelliJ IDEA.
4. Перший проєкт: створи новий Java-проєкт і файл Main.java.
Простими словами: ти пишеш код у файлі .java → компілятор перетворює його в байт-код → цей байт-код запускається через JVM.
Чим Java відрізняється від Python? Java більш строга і формальна, зате дуже добре привчає до правильної структури програми.

⌨ 2. Структура програми та перший вивід

У Java навіть найпростіша програма записується всередині класу. Це одна з головних особливостей мови. На початку це може виглядати важче, ніж у Python, але така структура добре підходить для великих проєктів.

2.1 Перша програма

public class Main { public static void main(String[] args) { System.out.println("Привіт, Світ!"); } }

У цьому прикладі:
public class Main — створює клас із назвою Main
public static void main(String[] args) — головний метод, з якого починається програма
System.out.println() — виводить текст у консоль

2.2 Чому це виглядає так довго?

Java вимагає чіткої структури. Тому навіть проста програма вже містить клас і метод. Але саме це робить код організованим і зручним для великої розробки.

Запам’ятай: якщо клас називається Main, то файл теж зазвичай має називатися Main.java.

🔧 3. Змінні та типи даних

Змінна — це місце в пам’яті, де зберігається значення. У Java мова строго типізована, тому тип змінної потрібно вказувати явно.

3.1 Основні типи даних

  • int — цілі числа
  • double — дробові числа
  • float — дробові числа меншої точності
  • boolean — true або false
  • char — один символ
  • String — текст

3.2 Приклади змінних

int quantity = 50; String product = "Кава"; boolean isActive = true; double price = 19.99; char grade = 'A';

3.3 Константи

Якщо значення не повинно змінюватися, використовують слово final.

final double PI = 3.14159;

Після цього значення PI вже не можна буде змінити.

Практика:
  • створи змінні для імені, віку та міста;
  • створи константу для числа PI;
  • виведи все в консоль.

📊 4. Оператори: арифметичні, порівняння та логіка

Оператори потрібні для того, щоб програма могла рахувати, порівнювати значення та перевіряти умови.

4.1 Арифметичні оператори

Оператор Що робить
+ додавання
- віднімання
* множення
/ ділення
% остача від ділення
int x = 10; int y = 3; System.out.println(x + y); System.out.println(x - y); System.out.println(x * y); System.out.println(x / y); System.out.println(x % y);

4.2 Оператори порівняння

Оператор Що означає
== дорівнює
!= не дорівнює
> більше
< менше
>= більше або дорівнює
<= менше або дорівнює
int age = 18; System.out.println(age == 18); System.out.println(age != 20); System.out.println(age > 16); System.out.println(age < 10); System.out.println(age >= 18); System.out.println(age <= 17);

4.3 Логічні оператори

Оператор Що робить
&& логічне "І"
|| логічне "АБО"
! логічне "НЕ"
int age = 20; boolean hasMoney = true; boolean canBuy = (age >= 18) && hasMoney; System.out.println(canBuy);

🔄 5. Керування потоком: умови

Керування потоком означає, що програма може не просто виконувати команди по черзі, а приймати рішення залежно від умов. Саме завдяки цьому Java-програма починає реагувати на дані користувача та різні ситуації.

У Java для цього використовують:
if — якщо умова правильна
else if — якщо попередня умова не підійшла, але ця правильна
else — якщо жодна з умов не спрацювала

5.1 if / else if / else

int score = 85; if (score >= 90) { System.out.println("Відмінно!"); } else if (score >= 70) { System.out.println("Добре!"); } else { System.out.println("Потрібно підтягнути знання."); }

У цьому прикладі:
— якщо оцінка 90 або більше, буде "Відмінно!"
— якщо менше 90, але 70 або більше, буде "Добре!"
— якщо нічого не підходить, виконається else

5.2 switch

switch зручно використовувати тоді, коли є одна змінна і кілька конкретних значень.

int day = 2; switch (day) { case 1: System.out.println("Понеділок"); break; case 2: System.out.println("Вівторок"); break; default: System.out.println("Інший день"); break; }

Тут програма перевіряє значення day. Якщо воно дорівнює 2, виведеться "Вівторок".

Практика:
  • перевірити, чи людина повнолітня;
  • знайти більше з двох чисел;
  • визначити день тижня через switch.

🔁 6. Цикли: for, while та do-while

Цикли потрібні для того, щоб повторювати одну й ту саму дію багато разів. Без них довелося б вручну писати однаковий код багато разів, а це довго і незручно.

У Java найчастіше використовують:
for — коли кількість повторів відома наперед
while — коли треба повторювати код, поки умова правильна
do-while — коли код повинен виконатися хоча б один раз

6.1 Цикл for

Це найзручніший цикл, коли ти знаєш, скільки разів потрібно повторити дію.

for (int i = 0; i < 5; i++) { System.out.println("Ітерація: " + i); }

Тут:
int i = 0 — початок
i < 5 — умова роботи циклу
i++ — збільшення лічильника на 1

6.2 Цикл while

while працює доти, доки умова істинна. Він підходить тоді, коли кількість повторів заздалегідь невідома.

int energy = 3; while (energy > 0) { System.out.println("Енергія: " + energy); energy--; }

У цьому прикладі цикл повторюється, поки енергія більша за нуль.

6.3 Цикл do-while

do-while дуже схожий на while, але код усередині нього виконується мінімум один раз.

int x = 10; do { System.out.println("Цей код виконається хоча б один раз"); } while (x < 5);

Навіть якщо умова x < 5 одразу неправильна, тіло циклу вже один раз виконається.

6.4 Чому цикли важливі?

Цикли потрібні в задачах на рахунок, масиви, меню, ігри, роботу з файлами, списками, даними користувача і ще в дуже багатьох ситуаціях. Це одна з основ програмування.

Обережно: якщо умова в while або do-while ніколи не стане хибною, програма може зациклитися.
Практика:
  • вивести числа від 1 до 10;
  • порахувати суму чисел від 1 до n;
  • вивести таблицю множення для числа;
  • написати зворотний відлік.

💬 7. Рядки та робота з текстом

У Java текст зберігається в типі String. Рядки використовуються майже в кожній програмі, тому що саме через них програма показує повідомлення, працює з іменами, логінами, паролями, меню, назвами товарів, описами та введенням користувача.

Простими словами, рядок — це послідовність символів, яку Java сприймає як одне текстове значення. Хоч це і здається простою темою, на практиці робота з рядками зустрічається постійно.

7.1 Створення рядка

Щоб створити текстову змінну, використовують тип String, а сам текст записують у подвійних лапках.

String name = "Віталік";

Тут у змінній name зберігається текстове значення "Віталік".

7.2 Об’єднання рядків

У Java рядки можна з’єднувати через оператор +. Це часто використовують для побудови повідомлень.

String firstName = "Віталік"; String text = "Привіт, " + firstName; System.out.println(text);

У результаті програма виведе Привіт, Віталік. Це зручно, коли частина тексту фіксована, а частина приходить зі змінної.

7.3 Об’єднання рядка і числа

У Java число теж можна об’єднати з рядком через +. У такому виразі число автоматично перетворюється на текст.

int age = 18; System.out.println("Мені " + age + " років");

Це часто використовується у виведенні даних у консоль.

7.4 Довжина рядка

Щоб дізнатися, скільки символів містить рядок, використовують метод length().

String word = "programming"; System.out.println(word.length());

Метод length() повертає кількість символів у рядку. Це корисно, наприклад, для перевірки довжини пароля або слова.

7.5 Доступ до символів

Іноді потрібно дістати окремий символ із рядка. Для цього використовують метод charAt().

String city = "Lviv"; System.out.println(city.charAt(0)); System.out.println(city.charAt(1));

У Java індексація починається з 0, тому:
charAt(0) — перший символ
charAt(1) — другий символ

7.6 Порівняння рядків

Окремо важливо пам’ятати: рядки в Java не варто порівнювати через == у звичайних задачах. Для перевірки однакового тексту використовують метод equals().

String a = "Java"; String b = "Java"; System.out.println(a.equals(b));

Тут програма перевіряє, чи однаковий текст міститься в обох змінних.

7.7 Чому рядки важливі?

Без рядків не обходиться майже жодна програма. Через них Java-програма спілкується з користувачем, показує помилки, читає дані й обробляє текстову інформацію. Тому ця тема хоч і проста на вигляд, але дуже практична.

Практика:
  • створи змінну з ім’ям;
  • виведи привітання;
  • порахуй довжину слова;
  • виведи перший символ рядка;
  • порівняй два рядки через equals().

🗃 8. Масиви та базові колекції

Масив — це набір елементів одного типу, які зберігаються під одним ім’ям. Він дуже потрібний, коли треба працювати не з одним значенням, а відразу з групою даних.

Наприклад, через масив можна зберігати:
— оцінки
— кілька чисел
— список результатів
— набір імен

8.1 Створення масиву

int[] numbers = {10, 20, 30, 40, 50};

Тут створено масив із п’яти цілих чисел.

8.2 Доступ до елементів

Щоб отримати окремий елемент масиву, потрібно звернутися до нього через індекс.

System.out.println(numbers[0]); System.out.println(numbers[2]);

У Java індексація починається з 0:
numbers[0] — перший елемент
numbers[1] — другий
numbers[2] — третій

8.3 Перебір масиву

Масив можна проходити циклом for.

for (int i = 0; i < numbers.length; i++) { System.out.println(numbers[i]); }

Тут numbers.length показує довжину масиву.

8.4 Колекція ArrayList

На відміну від масиву, ArrayList дозволяє динамічно додавати та видаляти елементи. Це дуже зручно в реальних програмах.

import java.util.ArrayList; ArrayList students = new ArrayList<>(); students.add("Іван"); students.add("Марія"); students.add("Олег"); for (String student : students) { System.out.println(student); }

Такий цикл називається enhanced for або for-each.

8.5 Чому це важливо?

Масиви і колекції використовуються майже всюди: в меню, таблицях, списках користувачів, результатах, оцінках і даних із бази.

Увага: якщо звернутися до неправильного індексу масиву, програма видасть помилку.
Практика:
  • створи масив із 5 чисел;
  • виведи всі елементи;
  • знайди суму елементів;
  • створи ArrayList зі списком імен.

📦 9. Методи

Метод у Java — це окремий блок коду, який виконує певну задачу. Методи потрібні для того, щоб не дублювати один і той самий код, а також щоб програма була чистішою, зручнішою і зрозумілішою.

Простими словами, метод — це як готова команда, яку ти створив сам. Один раз написав логіку, а потім можеш викликати її багато разів у різних місцях програми.

9.1 Метод без параметрів

Найпростіший варіант — метод, який не приймає жодних даних, а просто виконує певну дію.

public class Main { static void sayHi() { System.out.println("Привіт з методу!"); } public static void main(String[] args) { sayHi(); } }

Тут метод sayHi() просто виводить повідомлення. Коли ми викликаємо його в main, програма заходить у цей метод і виконує його код.

9.2 Метод з параметрами

Параметри дозволяють передавати в метод значення. Це означає, що один і той самий метод можна використовувати для різних даних.

static int add(int a, int b) { return a + b; }

У цьому прикладі:
int a і int b — параметри
int перед назвою методу означає, що метод повертає ціле число
return повертає результат назад

9.3 Виклик методу

Щоб використати метод, його треба викликати по імені та передати потрібні аргументи.

int result = add(5, 7); System.out.println(result);

Тут метод add отримає числа 5 і 7, порахує суму і поверне її у змінну result.

9.4 Навіщо потрібен return?

return повертає результат роботи методу назад туди, де його викликали. Саме завдяки цьому метод може не просто щось друкувати, а реально обчислювати значення і віддавати його далі програмі.

static int square(int x) { return x * x; }

Тут метод повертає квадрат числа. Після цього результат можна записати в змінну, вивести або використати в іншому обчисленні.

9.5 Перевантаження методів

У Java можна створювати кілька методів з однаковою назвою, якщо в них різні параметри. Це називається перевантаженням.

static int sum(int a, int b) { return a + b; } static double sum(double a, double b) { return a + b; }

Java сама визначить, який саме метод треба викликати, залежно від того, які аргументи ти передаєш.

9.6 Чому методи важливі?

Методи — це одна з основ хорошої структури програми. Саме вони допомагають розбити велику задачу на менші частини. Наприклад, окремий метод може рахувати суму, інший — показувати меню, третій — перевіряти пароль.

Чим краща структура методів, тим легше читати, тестувати й виправляти програму.

Порада: хороший метод зазвичай виконує одну зрозумілу задачу. Не треба намагатися втиснути всю логіку програми в один величезний метод.
Практика:
  • створи метод привітання;
  • створи метод для додавання двох чисел;
  • створи метод для квадрата числа;
  • створи перевантажений метод;
  • створи метод, який приймає ім’я і вік та виводить готовий текст.

🧠 10. Основи ООП: класи та об’єкти

Java — це об’єктно-орієнтована мова програмування, тому дуже важливо зрозуміти, що таке клас і об’єкт. Саме навколо цих понять будується більшість Java-програм.

На початку це може звучати складно, але ідея насправді проста:
клас — це шаблон або креслення
об’єкт — це конкретна створена сутність за цим шаблоном

Наприклад, клас Student — це опис того, яким має бути студент у програмі, а об’єкт — це вже конкретний студент зі своїм ім’ям і віком.

10.1 Клас

Клас описує, які дані та дії матиме майбутній об’єкт. Дані часто зберігаються у полях, а дії описуються через методи.

class Student { String name; int age; }

У цьому прикладі клас Student має два поля:
name — ім’я студента
age — його вік

10.2 Об’єкт

Об’єкт — це конкретний екземпляр класу. Щоб створити об’єкт у Java, використовують слово new.

Student s1 = new Student(); s1.name = "Віталік"; s1.age = 18;

Тут:
new Student() — створює новий об’єкт
s1 — змінна, яка зберігає цей об’єкт
далі ми задаємо значення його полям

10.3 Метод усередині класу

Клас може не тільки зберігати дані, а й виконувати дії. Для цього всередині класу створюють методи.

class Student { String name; int age; void showInfo() { System.out.println("Ім'я: " + name + ", Вік: " + age); } }

Тепер кожен об’єкт класу Student може сам показати свою інформацію через метод showInfo().

10.4 Виклик методу об’єкта

Student s1 = new Student(); s1.name = "Віталік"; s1.age = 18; s1.showInfo();

Коли ми викликаємо s1.showInfo(), об’єкт використовує свої власні дані та виконує закладену в ньому дію.

10.5 Чому ООП важливе?

ООП допомагає будувати великі програми більш логічно. Замість хаотичного набору змінних і функцій, ти працюєш із сутностями: студентами, автомобілями, товарами, замовленнями, користувачами.

Саме тому Java часто використовують для великих систем: класи й об’єкти допомагають тримати код у порядку.

Просте запам’ятовування:
клас — шаблон
об’єкт — конкретний екземпляр
поля — дані об’єкта
методи — дії об’єкта
Практика:
  • створи клас Car з полями brand і year;
  • створи об’єкт цього класу;
  • додай метод для виведення інформації;
  • створи ще один об’єкт із іншими даними.

⚠ 11. Типові помилки новачків

  • Забутий ; — у Java більшість команд закінчуються крапкою з комою.
  • Неправильні дужки — Java дуже чутлива до структури { }.
  • Плутанина між = і ==.
  • Невірний індекс масиву.
  • Спроба використати змінну без правильного типу.
  • Забутий main — без нього програма не стартує як звичайний консольний застосунок.
Порада: якщо Java показує помилку, дуже часто проблема в дрібниці: дужка, крапка з комою, неправильне ім’я або невідповідність типу.
