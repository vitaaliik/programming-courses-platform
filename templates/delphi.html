Курс: Delphi

Повний вступ у Delphi та Object Pascal: від базового синтаксису до створення простих застосунків.

🎯 Для кого цей курс?

Цей курс створений для початківців, які хочуть вивчити Delphi з нуля. Матеріал підібраний так, щоб людина поступово зрозуміла основу мови Object Pascal, навчилась працювати із змінними, умовами, циклами, процедурами та елементами інтерфейсу.

Після проходження курсу ти зможеш:

  • розуміти, як побудована програма на Delphi;
  • створювати прості консольні та візуальні програми;
  • працювати зі змінними, умовами, циклами та функціями;
  • створювати обробники кнопок і працювати з компонентами форми;
  • розуміти базову логіку RAD Studio та Object Pascal.
Головна мета курсу: дати тобі реальну базу для створення своїх перших програм і форм у Delphi, а не просто суху теорію.

📜 Історія та Призначення

Delphi був випущений компанією Borland у 1995 році як середовище швидкої розробки застосунків, яке працює на основі мови Object Pascal. Його головною перевагою була можливість дуже швидко створювати програми з графічним інтерфейсом.

Де використовується Delphi?

  • Настільні програми Windows: швидке створення нативних застосунків з кнопками, формами та полями вводу.
  • Корпоративні системи: бухгалтерія, логістика, медицина, внутрішні бази даних.
  • Робота з БД: клієнтські програми для MySQL, Access, SQL Server та інших СУБД.
  • Кросплатформна розробка: через FireMonkey можна створювати застосунки для Windows, Android, macOS та інших платформ.
Важливо: Delphi сьогодні не така популярна, як C#, Java чи Python, але вона досі використовується, особливо там, де вже є великі старі системи або потрібна швидка розробка десктопних програм.

📂 1. Вступ: Як налаштувати все для роботи

Щоб працювати в Delphi, зазвичай використовують RAD Studio або середовище Delphi, де можна створювати як консольні, так і візуальні програми.

Що таке RAD?

RAD означає Rapid Application Development — швидка розробка застосунків. Головна ідея Delphi в тому, що ти можеш не тільки писати код, а й перетягувати візуальні елементи на форму: кнопки, поля, написи, таблиці.

1. Встановлення: відкрий RAD Studio або Delphi і створи новий проєкт.
2. Вибір типу програми: можна створити Console Application для простих задач або VCL Forms Application для віконних програм.
3. Форма: якщо це візуальний проєкт, ти одразу побачиш форму, на яку можна розміщувати компоненти.
4. Код: подвійний клік по кнопці або іншому компоненту відкриє обробник події, де пишеться логіка.
Простими словами: у Delphi ти можеш одночасно працювати як із кодом, так і з готовими візуальними елементами. Через це Delphi особливо зручний для навчання створення програм з інтерфейсом.

⌨ 2. Структура програми та базовий синтаксис

Мова Delphi базується на Object Pascal. Вона має свій особливий стиль запису, який відрізняється від C++, C# чи Java. Тут важливо звикнути до ключових слів begin, end, var, procedure, function.

2.1 Консольна програма

У найпростішому варіанті програма починається словом program, а весь основний код знаходиться між begin і end.

program MyFirstApp; {$APPTYPE CONSOLE} begin Writeln('Привіт, Світ!'); Readln; end.

У цьому прикладі:
program MyFirstApp; — назва програми
{$APPTYPE CONSOLE} — вказує, що це консольна програма
begin ... end. — основний блок коду
Writeln — виводить текст у консоль
Readln — чекає натискання Enter

2.2 Блоки begin / end

У Delphi майже всі великі блоки коду оформляються через begin і end. Це дуже важливо, бо саме так мова розуміє межі команд.

Пам’ятай: у кінці всієї програми ставиться end. з крапкою, а в середині блоків зазвичай використовується end; з крапкою з комою.

🔧 3. Змінні та типи даних

Змінна — це область пам’яті, де програма зберігає значення. У Delphi змінні зазвичай оголошуються в секції var.

3.1 Основні типи даних

  • Integer — цілі числа
  • Real — дробові числа
  • Boolean — логічне значення: True або False
  • Char — один символ
  • String — текст

3.2 Оголошення змінних

У Delphi спочатку пишеться назва змінної, потім двокрапка, а потім тип.

var UserName: String; UserAge: Integer; Price: Real; IsStudent: Boolean;

3.3 Присвоєння значення

У Delphi для присвоєння значення використовується оператор :=.

UserName := 'Олег'; UserAge := 20; Price := 199.99; IsStudent := True;

Це одна з головних відмінностей від C-подібних мов. У Delphi:
:= — присвоїти значення
= — використовується у перевірках або описах, але не для звичайного присвоєння змінній.

3.4 Приклад у процедурі кнопки

procedure TForm1.Button1Click(Sender: TObject); var UserName: String; UserAge: Integer; begin UserName := 'Олег'; UserAge := 20; ShowMessage('Ім''я: ' + UserName + ' Вік: ' + IntToStr(UserAge)); end;
Практика:
  • створи змінні для імені, віку і міста;
  • присвой їм значення;
  • виведи все через ShowMessage або Writeln.

📊 4. Оператори: арифметичні, порівняння та логіка

Оператори потрібні для того, щоб програма могла виконувати обчислення, порівнювати значення та приймати рішення.

4.1 Арифметичні оператори

Оператор Що робить
+ додавання
- віднімання
* множення
/ ділення
mod остача від ділення
var A, B: Integer; begin A := 10; B := 3; Writeln(A + B); Writeln(A - B); Writeln(A * B); Writeln(A div B); Writeln(A mod B); end;

4.2 Оператори порівняння

Ці оператори потрібні, щоб перевіряти умови. Результат завжди буде True або False.

Оператор Що означає
= дорівнює
<> не дорівнює
> більше
< менше
>= більше або дорівнює
<= менше або дорівнює
var Age: Integer; begin Age := 18; Writeln(Age = 18); Writeln(Age <> 20); Writeln(Age > 16); Writeln(Age < 10); Writeln(Age >= 18); Writeln(Age <= 17); end;

4.3 Логічні оператори

Оператор Що робить
and логічне "І"
or логічне "АБО"
not логічне "НЕ"
var Age: Integer; HasMoney: Boolean; CanBuy: Boolean; begin Age := 20; HasMoney := True; CanBuy := (Age >= 18) and HasMoney; Writeln(CanBuy); end;

🔄 5. Керування потоком: умови та цикли

Керування потоком — це можливість програми приймати рішення і повторювати дії. Саме завдяки цьому програма перестає бути просто набором рядків, які виконуються зверху вниз, і починає реагувати на різні ситуації.

Наприклад, програма може:
— перевірити, чи людина повнолітня
— визначити, яке число більше
— багато разів виконати одну й ту саму дію
— повторювати код, поки не виконається потрібна умова

У Delphi для цього використовують if then else, case, for, while і repeat until.

5.1 if then else

Оператор if перевіряє умову. Якщо вона правильна, виконується один блок коду. Якщо ні — виконується інший. Це основа будь-якої логіки в програмуванні.

У Delphi після умови пишеться слово then. Якщо є альтернативний варіант, використовується else.

var Score: Integer; begin Score := 85; if Score >= 90 then Writeln('Відмінно!') else if Score >= 70 then Writeln('Добре!') else Writeln('Потрібно підтягнути знання.'); end;

У цьому прикладі програма перевіряє оцінку:
— якщо 90 або більше, виводиться 'Відмінно!'
— якщо менше 90, але 70 або більше, виводиться 'Добре!'
— якщо не підходить жодна умова, спрацьовує else

5.2 case

case використовують тоді, коли є одна змінна і кілька чітких значень, які треба перевірити. Це зручніше і чистіше, ніж писати багато if підряд.

var Day: Integer; begin Day := 2; case Day of 1: Writeln('Понеділок'); 2: Writeln('Вівторок'); 3: Writeln('Середа'); else Writeln('Інший день'); end; end;

Тут програма дивиться на значення змінної Day. Якщо воно дорівнює 2, буде виведено 'Вівторок'. Якщо жоден варіант не підійде, виконається блок else всередині case.

5.3 Цикл for

Цикл for використовують тоді, коли кількість повторів відома наперед. Наприклад, якщо треба вивести числа від 1 до 10 або кілька разів виконати одну й ту саму дію.

У Delphi цикл for має такий вигляд:
— створюється лічильник
— задається початкове і кінцеве значення
— цикл автоматично змінює лічильник після кожного повтору

var i: Integer; begin for i := 1 to 5 do begin Writeln('Крок: ', i); end; end;

Тут змінна i починається з 1 і збільшується до 5. На кожному кроці програма виводить номер поточного повтору.

5.4 Цикл while

while використовують тоді, коли кількість повторів наперед невідома. Він працює доти, доки умова істинна.

Це цикл з передумовою, тому що умова перевіряється до виконання коду.

var Energy: Integer; begin Energy := 3; while Energy > 0 do begin Writeln('Енергія: ', Energy); Energy := Energy - 1; end; end;

У цьому прикладі програма буде повторювати код, поки Energy > 0. Після кожного повтору енергія зменшується, і коли вона стане 0, цикл завершиться.

5.5 Цикл repeat until

Цикл repeat until схожий на while, але має одну важливу різницю: код всередині нього гарантовано виконається хоча б один раз.

Це відбувається тому, що умова перевіряється вже після виконання тіла циклу.

var X: Integer; begin X := 10; repeat Writeln('Цей код виконається хоча б один раз'); until X < 5; end;

Навіть якщо умова X < 5 неправильна вже з самого початку, код у repeat все одно виконається один раз.

Порада: якщо треба, щоб код обов’язково спрацював хоча б один раз, часто зручніше використовувати саме repeat until.
Практика:
  • перевірити, чи число парне;
  • знайти більше з двох чисел;
  • вивести числа від 1 до 10;
  • порахувати суму чисел від 1 до n.

💬 6. Рядки та робота з текстом

У Delphi тип String використовується для роботи з текстом: іменами, повідомленнями, введенням користувача, описами та будь-якими словами чи реченнями. У реальних програмах текст використовується дуже часто, тому ця тема обов’язкова для новачка.

Наприклад, через рядки можна:
— зберігати ім’я користувача
— будувати повідомлення
— виводити дані на екран
— з’єднувати текст з числами після перетворення

6.1 Створення рядка

Щоб створити текстову змінну, у Delphi використовують тип String. Текст записують в одинарних лапках.

var Name: String; begin Name := 'Віталік'; end;

Тут у змінній Name зберігається текст 'Віталік'.

6.2 Об'єднання рядків

Щоб з’єднати два рядки або текст і змінну, у Delphi використовують оператор +.

var FirstName, Text: String; begin FirstName := 'Віталік'; Text := 'Привіт, ' + FirstName; ShowMessage(Text); end;

У результаті програма покаже повідомлення Привіт, Віталік.

6.3 Перетворення числа в текст

Якщо треба з’єднати рядок із числом, число спочатку треба перетворити у текст. Для цього часто використовують функцію IntToStr.

var Age: Integer; begin Age := 18; ShowMessage('Мені ' + IntToStr(Age) + ' років'); end;

Без такого перетворення програма не зможе напряму з’єднати число і текст.

6.4 Перетворення тексту в число

Інколи ситуація зворотна: користувач вводить текст, а програмі потрібно отримати число. Для цього використовують функції на кшталт StrToInt.

var AgeText: String; Age: Integer; begin AgeText := '25'; Age := StrToInt(AgeText); Writeln(Age); end;

Тут текст '25' перетворюється в ціле число 25.

6.5 Довжина рядка

Щоб дізнатися, скільки символів у слові або реченні, використовують функцію Length.

var Word: String; begin Word := 'programming'; Writeln(Length(Word)); end;

Ця команда виведе кількість символів у слові programming.

Порада: у Delphi дуже часто доводиться перетворювати дані між текстом і числами. Це одна з найтиповіших тем у простих програмах і формах.
Практика:
  • створи змінну з ім’ям користувача;
  • з’єднай її з текстом привітання;
  • виведи повідомлення з числом через IntToStr;
  • порахуй довжину слова.

🗃 7. Масиви

Масив — це набір кількох елементів одного типу, які зберігаються під одним ім’ям. Він потрібен тоді, коли треба працювати не з одним значенням, а одразу з цілою групою даних.

Наприклад, через масив можна зберігати:
— оцінки студента
— кілька чисел
— список результатів
— набір символів або рядків

7.1 Створення масиву

У Delphi масив оголошується через слово array. Після цього в квадратних дужках вказується діапазон індексів, а потім — тип елементів.

var Numbers: array[1..5] of Integer; begin Numbers[1] := 10; Numbers[2] := 20; Numbers[3] := 30; Numbers[4] := 40; Numbers[5] := 50; end;

Тут створений масив із п’яти цілих чисел. Важливо, що в Delphi масив може починатися не тільки з 0. У цьому прикладі індекси йдуть від 1 до 5.

7.2 Доступ до елементів

Щоб звернутися до конкретного елемента, потрібно вказати його індекс у квадратних дужках.

Writeln(Numbers[1]); Writeln(Numbers[3]);

Тут буде виведено перший і третій елемент масиву.

7.3 Перебір масиву циклом

Найчастіше масив проходять циклом for, щоб не писати окремий рядок для кожного елемента.

var i: Integer; begin for i := 1 to 5 do Writeln(Numbers[i]); end;

У цьому прикладі цикл по черзі бере всі елементи масиву від 1 до 5 і виводить їх на екран.

7.4 Чому масиви важливі?

Масиви — це одна з базових структур у програмуванні. Без них складно переходити до серйозніших задач, бо майже скрізь треба працювати з наборами даних, а не з однією окремою змінною.

7.5 Що треба пам’ятати новачку?

Найголовніше — не плутати межі масиву. Якщо масив оголошено як array[1..5], то звернення до Numbers[0] або Numbers[6] уже буде неправильним.

Увага: у Delphi межі масиву ти задаєш сам. Саме тому завжди треба пам’ятати, з якого індексу починається твій масив.
Практика:
  • створи масив із 5 чисел;
  • виведи всі елементи циклом;
  • знайди суму всіх елементів;
  • знайди найбільше число в масиві.

📦 8. Процедури та функції

У Delphi код часто розбивають на процедури та функції. Це робить програму чистішою, зрозумілішою і зручнішою для повторного використання. Якщо один і той самий код починає повторюватися, це знак, що його краще винести в окрему процедуру або функцію.

Простими словами:
— процедура виконує дію
— функція виконує дію і повертає результат

8.1 Процедура

Процедура використовується тоді, коли треба просто щось зробити: вивести текст, змінити значення, показати повідомлення.

procedure SayHi; begin Writeln('Привіт з процедури!'); end;

Тут процедура SayHi просто виводить текст у консоль.

8.2 Виклик процедури

Щоб виконати процедуру, її треба просто викликати по імені.

begin SayHi; end;

Після такого виклику програма зайде в процедуру і виконає її код.

8.3 Функція

Функція схожа на процедуру, але вона обов’язково повертає результат. Це зручно, коли треба не просто щось виконати, а ще й отримати значення назад.

function Add(A, B: Integer): Integer; begin Result := A + B; end;

У цьому прикладі функція Add приймає два числа і повертає їх суму. Ключове слово Result зберігає те значення, яке поверне функція.

8.4 Виклик функції

Коли функція викликається, її результат можна записати в змінну або одразу використати у виразі.

var Sum: Integer; begin Sum := Add(5, 7); Writeln(Sum); end;

Тут функція додає два числа, а результат зберігається у змінній Sum.

8.5 Передача параметрів через var

У Delphi параметри можна передавати не тільки як звичайні значення, а й через var. Це означає, що процедура або функція буде працювати не з копією, а з реальною змінною, і зможе змінити її початкове значення.

procedure AddTen(var X: Integer); begin X := X + 10; end;

Якщо передати змінну в цю процедуру, її значення після виклику реально зміниться.

8.6 Чому це важливо?

Процедури та функції — одна з найважливіших тем у програмуванні. Саме вони дозволяють будувати програму не як хаотичний набір рядків, а як акуратно розділену систему з окремих частин.

Запам’ятай: процедура — робить дію, функція — повертає результат.
Практика:
  • створи процедуру привітання;
  • створи функцію для додавання двох чисел;
  • створи процедуру, яка змінює значення через var.

🖱 9. Компоненти форми: кнопки, поля та події

Одна з головних переваг Delphi — це можливість створювати програми не тільки через код, а й через візуальний інтерфейс. Ти можеш відкрити форму, перетягнути на неї кнопку, поле вводу, напис і буквально за кілька хвилин отримати працюючу програму з вікном.

Саме через це Delphi дуже зручний для навчання створення прикладних програм. Тут легко зрозуміти зв’язок між тим, що бачить користувач на екрані, і тим, який код виконується після натискання кнопки або введення тексту.

9.1 Основні компоненти

У Delphi є багато готових компонентів, але новачку спочатку достатньо знати кілька основних:

  • TButton — кнопка, на яку можна натискати
  • TEdit — поле для введення тексту
  • TLabel — напис, який показує текст
  • TMemo — багаторядкове текстове поле

Ці компоненти додаються на форму через конструктор форми в RAD Studio.

9.2 Подія кнопки

Коли користувач натискає кнопку, Delphi виконує спеціальну процедуру — обробник події. Найчастіше це подія OnClick.

procedure TForm1.Button1Click(Sender: TObject); begin ShowMessage('Кнопку натиснуто!'); end;

Тут, після натискання на кнопку Button1, з’явиться вікно з повідомленням.

9.3 Зчитування тексту з поля вводу

У компоненті TEdit введений користувачем текст знаходиться у властивості Text.

procedure TForm1.Button1Click(Sender: TObject); begin ShowMessage('Привіт, ' + Edit1.Text); end;

У цьому прикладі користувач вводить своє ім’я в поле Edit1, а після натискання кнопки програма показує привітання.

9.4 Зміна напису Label

Компонент TLabel використовують для показу тексту на формі. Текст зберігається у властивості Caption.

procedure TForm1.Button1Click(Sender: TObject); begin Label1.Caption := 'Новий текст'; end;

Після натискання кнопки напис на формі зміниться на Новий текст.

9.5 Чому це важливо?

Робота з формами та компонентами — це одна з ключових особливостей Delphi. Саме тут починається справжня прикладна розробка: програма вже не просто виводить щось у консоль, а взаємодіє з користувачем через вікна, кнопки та поля.

Коли ти розумієш, як працюють кнопки, події, поля вводу та написи, ти вже можеш створювати:
— прості калькулятори
— форми входу
— анкети користувача
— віконні програми для роботи з даними

Практика:
  • додай на форму кнопку і поле вводу;
  • зчитай текст із поля;
  • виведи його через ShowMessage;
  • зміни напис у Label після натискання кнопки.

⚠ 10. Типові помилки новачків

  • Плутанина між := і = — у Delphi для присвоєння використовується саме :=.
  • Забутий begin або end — це дуже часта причина помилок.
  • Забута крапка з комою — багато рядків у Delphi закінчуються ;.
  • Проблеми з лапками в рядках — якщо в тексті є апостроф, його треба екранувати подвійним апострофом.
  • Неправильне перетворення типів — для чисел і тексту часто потрібні IntToStr, StrToInt та інші функції.
  • Невірний індекс масиву — у Delphi масив може починатися з 1 або з іншого значення, якщо ти так оголосив.
var Age: Integer; begin Age := StrToInt(Edit1.Text); end;

Тут текст із поля вводу перетворюється в число. Якщо користувач введе не число, програма може видати помилку.
