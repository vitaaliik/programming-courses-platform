Курс: JavaScript

Повний вступ у JavaScript для початківця: від базового синтаксису до інтерактивних веб-сторінок.

🎯 Для кого цей курс?

Цей курс створений для початківців, які вже бачили HTML/CSS або тільки починають цікавитися веб-розробкою і хочуть зрозуміти, як зробити сайт не просто красивим, а ще й живим та інтерактивним.

JavaScript — це саме та мова, яка дозволяє сторінці реагувати на дії користувача: натискання кнопок, введення тексту, відкриття меню, зміну вмісту, перевірку форм і багато іншого.

Після проходження курсу ти зможеш:

  • підключати JavaScript до HTML-сторінки;
  • створювати змінні та працювати з даними;
  • використовувати умови, цикли і функції;
  • реагувати на події користувача;
  • змінювати HTML через JavaScript;
  • створювати прості інтерактивні веб-сторінки.
Головна мета курсу: дати тобі не просто окремі приклади, а реальну базу, після якої ти вже зможеш сам написати просту логіку для сайту.

📜 Історія та Призначення

JavaScript був створений у 1995 році Бренданом Айком. Спочатку мова задумувалась як легкий інструмент для додавання простих дій на веб-сторінку, але з часом JavaScript виріс у повноцінну мову програмування, яка сьогодні використовується і на клієнті, і на сервері.

Де використовують JavaScript?

  • Frontend: логіка для сайтів, кнопок, меню, форм, анімацій.
  • Backend: через Node.js JavaScript можна використовувати на сервері.
  • Веб-застосунки: React, Vue, Angular та інші фреймворки базуються на JavaScript.
  • Браузерні ігри: JavaScript дозволяє створювати прості ігри прямо в браузері.
  • Автоматизація: різні скрипти для роботи з даними, сторінками та інтерфейсами.
Пам’ятай: HTML створює структуру сторінки, CSS відповідає за стиль, а JavaScript додає поведінку і логіку.

📂 1. Як підключити JavaScript до сторінки

Щоб JavaScript почав працювати на сайті, його потрібно підключити до HTML-документа. Це можна зробити двома основними способами: написати код прямо в HTML або винести його в окремий файл.

1.1 Вбудований спосіб

JavaScript можна написати прямо всередині HTML через тег <script>.

<script> alert("Привіт!"); </script>

Такий варіант підходить для дуже маленьких прикладів, але в реальних проєктах краще так не робити.

1.2 Окремий файл

Найправильніший підхід — винести JavaScript в окремий файл, наприклад script.js.

<script src="script.js"></script>

Тоді HTML відповідає за структуру сторінки, CSS — за стиль, а JavaScript — за логіку. Це чистіше, зручніше і грамотно організовано.

Порада: тег <script> зазвичай ставлять перед закриваючим тегом </body>, щоб HTML спочатку завантажився, а вже потім виконався JavaScript.

🔧 2. Змінні, типи даних та виведення інформації

Змінна — це місце, де програма зберігає значення. У JavaScript змінні потрібні для зберігання тексту, чисел, логічних значень та інших даних.

2.1 Створення змінних

У сучасному JavaScript найчастіше використовують let і const.

let name = "Віталік"; const age = 18; let isStudent = true;

let використовують тоді, коли значення може змінюватися, а const — коли значення має залишатися сталим.

2.2 Основні типи даних

  • string — текст
  • number — числа
  • boolean — true або false

2.3 Виведення інформації

У JavaScript часто використовують console.log(), щоб подивитися значення в консолі браузера.

let userName = "Віталік"; console.log(userName);

Це корисно для перевірки, що відбувається в коді.

2.4 Об’єднання тексту

let nameUser = "Віталік"; let text = "Привіт, " + nameUser; console.log(text);

У результаті в консолі буде виведено Привіт, Віталік.

Практика:
  • створи змінні для імені, віку та міста;
  • виведи їх у консоль;
  • створи повідомлення з цих змінних.

📊 3. Оператори: арифметичні, порівняння та логіка

Оператори потрібні для того, щоб JavaScript міг виконувати обчислення, порівнювати значення та перевіряти умови.

3.1 Арифметичні оператори

Оператор Що робить
+ додавання
- віднімання
* множення
/ ділення
% остача від ділення
let x = 10; let y = 3; console.log(x + y); console.log(x - y); console.log(x * y); console.log(x / y); console.log(x % y);

3.2 Оператори порівняння

Ці оператори повертають true або false.

Оператор Що означає
== дорівнює
!= не дорівнює
> більше
< менше
>= більше або дорівнює
<= менше або дорівнює
let age = 18; console.log(age == 18); console.log(age > 16); console.log(age < 10);

3.3 Логічні оператори

Оператор Що робить
&& логічне "І"
|| логічне "АБО"
! логічне "НЕ"
let ageUser = 20; let hasMoney = true; let canBuy = (ageUser >= 18) && hasMoney; console.log(canBuy);

🔄 4. Керування потоком: умови

Умови дозволяють програмі приймати рішення. Саме завдяки їм сторінка може поводитись по-різному залежно від даних або дій користувача.

4.1 if / else if / else

Це базова конструкція для перевірки умов.

let score = 85; if (score >= 90) { console.log("Відмінно!"); } else if (score >= 70) { console.log("Добре!"); } else { console.log("Потрібно підтягнути знання."); }

У цьому прикладі програма перевіряє оцінку і залежно від значення виводить різний результат.

Практика:
  • перевірити, чи людина повнолітня;
  • знайти більше з двох чисел;
  • перевірити, чи число парне.

🔁 5. Цикли: for та while

Цикли потрібні для того, щоб багато разів повторювати один і той самий код. Це дуже важливо, бо без циклів довелося б вручну писати ті самі команди знову і знову.

5.1 Цикл for

Цикл for зручний тоді, коли кількість повторів відома наперед.

for (let i = 0; i < 5; i++) { console.log(i); }

Тут:
let i = 0 — початкове значення
i < 5 — умова роботи циклу
i++ — збільшення на 1 після кожного повтору

5.2 Цикл while

Цикл while працює доти, доки умова істинна.

let energy = 3; while (energy > 0) { console.log("Енергія: " + energy); energy--; }

Тут програма буде повторювати код, поки значення energy більше за нуль.

Обережно: якщо умова в while ніколи не стане хибною, вийде нескінченний цикл.
Практика:
  • вивести числа від 1 до 10;
  • порахувати суму чисел;
  • зробити зворотний відлік.

📦 6. Функції

Функція — це окремий блок коду, який виконує певну задачу. Функції потрібні для того, щоб не дублювати логіку і робити код чистішим.

6.1 Функція без параметрів

function sayHi() { console.log("Привіт!"); } sayHi();

Тут функція просто виконує одну дію — виводить повідомлення.

6.2 Функція з параметрами

Параметри дозволяють передавати в функцію дані.

function add(a, b) { return a + b; } let result = add(5, 7); console.log(result);

У цьому прикладі функція додає два числа і повертає результат через return.

Пам’ятай: хороша функція зазвичай виконує одну зрозумілу задачу.
Практика:
  • створи функцію привітання;
  • створи функцію для квадрата числа;
  • створи функцію для додавання двох чисел.

👆 7. Події: клік, введення та взаємодія з користувачем

Одна з головних причин, чому JavaScript такий важливий для сайтів, — це робота з подіями. Подія — це дія, яка сталася на сторінці: користувач натиснув кнопку, ввів текст, навів курсор або відправив форму.

Саме через події сайт починає реагувати на користувача.

7.1 Обробка кліку

Найпростіший приклад — реакція на натискання кнопки.

<button onclick="clickMe()">Натисни</button> <script> function clickMe() { alert("Ти натиснув кнопку!"); } </script>

Тут після кліку по кнопці викликається функція clickMe(), і браузер показує повідомлення.

7.2 Подія введення

JavaScript може реагувати не тільки на клік, а й на зміну тексту в полі.

<input type="text" id="nameInput">

Пізніше цей текст можна зчитати через JavaScript і використати в програмі.

7.3 Чому події важливі?

Події — це основа будь-якої взаємодії на сайті. Без них кнопки нічого не робили б, форми не перевірялися б, а меню не відкривалися б.

Практика:
  • зроби кнопку, яка показує повідомлення;
  • зроби кнопку, яка змінює текст;
  • спробуй зчитати текст із input.

💻 8. DOM: зміна HTML через JavaScript

DOM — це об’єктне представлення HTML-сторінки. Простими словами, браузер перетворює HTML у структуру, з якою JavaScript може працювати: знаходити елементи, змінювати їх, ховати, показувати, міняти текст або стиль.

8.1 Пошук елемента за id

<p id="text">Старий текст</p> <script> document.getElementById("text").innerText = "Новий текст"; </script>

У цьому прикладі JavaScript знаходить елемент з id text і змінює його текст.

8.2 Зміна стилю елемента

document.getElementById("text").style.color = "red";

Так можна змінити колір тексту через JavaScript.

8.3 Чому DOM такий важливий?

Саме через DOM JavaScript “оживляє” сторінку. Якщо сайт щось змінює без перезавантаження, відкриває меню, показує повідомлення, міняє блоки — це майже завжди робота з DOM.

Порада: спочатку треба навчитись знаходити елементи і міняти їхній текст — це вже дуже сильна база для початку.
Практика:
  • зміни текст абзацу через кнопку;
  • зміни колір елемента;
  • сховай або покажи блок через JavaScript.

⚠ 9. Типові помилки новачків

  • Неправильне ім’я змінної — одна зайва буква, і код уже не працює.
  • Плутанина між = і ==.
  • Забутий символ — дужка, лапка або фігурна дужка.
  • Неправильний id елемента — JavaScript не може знайти елемент.
  • Код запускається раніше, ніж завантажився HTML.
  • Нескінченний цикл — умова в while ніколи не стає хибною.
Порада: якщо JavaScript “не працює”, перше місце, куди треба дивитися, — це консоль браузера.
