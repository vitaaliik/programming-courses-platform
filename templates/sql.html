Курс: SQL

Повний вступ у SQL для початківця: від таблиць і простих запитів до JOIN, GROUP BY та роботи з реальними даними.

🎯 Для кого цей курс?

Цей курс створений для початківців, які хочуть зрозуміти, як працюють бази даних і як через SQL отримувати, додавати, змінювати та видаляти інформацію. Матеріал побудований так, щоб людина поступово перейшла від простих таблиць до більш реальних запитів.

Після проходження курсу ти зможеш:

  • розуміти, що таке таблиця, запис, поле і ключ;
  • створювати таблиці та додавати в них дані;
  • писати запити через SELECT, WHERE, ORDER BY;
  • оновлювати та видаляти записи;
  • об’єднувати таблиці через JOIN;
  • використовувати GROUP BY та агрегатні функції.
Головна мета курсу: дати тобі не просто окремі SQL-команди, а реальну базу для роботи з таблицями і даними в навчальних та практичних проєктах.

📜 Історія та Призначення

SQL — це мова запитів до баз даних. Її назва розшифровується як Structured Query Language. SQL використовують для роботи з реляційними базами даних, де інформація зберігається у вигляді таблиць.

Простими словами, SQL потрібен для того, щоб сказати базі даних:
— створити таблицю
— додати новий запис
— знайти потрібні рядки
— змінити дані
— видалити інформацію
— поєднати кілька таблиць між собою

Де використовується SQL?

  • Сайти та веб-застосунки: користувачі, замовлення, товари, коментарі.
  • Бізнес-системи: склад, бухгалтерія, клієнти, продажі.
  • Аналітика: запити до великих обсягів даних.
  • Мобільні та десктопні програми: зберігання і вибірка інформації.
Важливо: SQL — це не мова загального програмування як Python чи Java. Вона спеціально створена саме для роботи з даними в таблицях.

📂 1. База даних, таблиці та записи

База даних — це місце, де зберігається інформація. У SQL ця інформація найчастіше організована у вигляді таблиць.

Таблицю можна уявити як Excel:
— є стовпці, які описують, які саме дані зберігаються
— є рядки, які містять конкретні записи

1.1 Приклад таблиці users

Наприклад, у таблиці users можуть бути такі стовпці:

  • id — ідентифікатор користувача
  • name — ім’я
  • age — вік

Один рядок у такій таблиці — це вже конкретний користувач, наприклад:
1 | Іван | 20

1.2 Чому таблиці важливі?

Бо вся подальша робота в SQL будується навколо таблиць. Якщо ти зрозумів таблиці, стовпці, рядки та типи полів — то вже маєш правильний фундамент для всього іншого.

📦 2. Створення таблиці: CREATE TABLE

Щоб почати працювати з даними, спочатку треба створити таблицю. Для цього використовують команду CREATE TABLE.

2.1 Простий приклад створення таблиці

CREATE TABLE users ( id INT, name VARCHAR(50), age INT );

У цьому прикладі:
users — назва таблиці
id INT — числове поле
name VARCHAR(50) — текстове поле до 50 символів
age INT — ще одне числове поле

2.2 Типи даних

Кожне поле має свій тип. Це важливо, бо база даних має розуміти, що саме там зберігається: число, текст, дата тощо.

  • INT — цілі числа
  • VARCHAR(n) — текст змінної довжини
  • DATE — дата
  • DECIMAL — дробові числа, наприклад для цін
Порада: типи полів треба обирати уважно. Якщо вік — це число, то його не треба зберігати як текст.

➕ 3. Додавання даних: INSERT INTO

Після створення таблиці в неї можна додавати записи. Для цього використовують команду INSERT INTO.

3.1 Додавання одного запису

INSERT INTO users (id, name, age) VALUES (1, 'Іван', 20);

Тут ми додаємо нового користувача в таблицю users.

3.2 Додавання кількох записів

INSERT INTO users (id, name, age) VALUES (2, 'Марія', 19), (3, 'Олег', 22), (4, 'Анна', 18);

Так можна одразу додати кілька рядків.

Пам’ятай: порядок значень у VALUES має відповідати порядку полів у дужках після назви таблиці.

🔍 4. Отримання даних: SELECT

Команда SELECT використовується для отримання інформації з таблиці. Це одна з найважливіших SQL-команд.

4.1 Отримати всі стовпці

SELECT * FROM users;

Зірочка * означає: взяти всі поля таблиці.

4.2 Отримати тільки конкретні поля

SELECT name, age FROM users;

Тут буде вибрано тільки ім’я та вік користувачів.

4.3 Чому SELECT такий важливий?

Бо саме через нього ти дістаєш потрібні дані. У реальних проєктах ти майже постійно працюєш із вибіркою інформації: список користувачів, товари, замовлення, оцінки, клієнти і так далі.

⚙ 5. Фільтрація даних: WHERE

Команда WHERE дозволяє не просто дістати всі дані, а вибрати тільки ті записи, які підходять під певну умову.

5.1 Простий приклад

SELECT * FROM users WHERE age > 18;

Тут ми отримаємо тільки тих користувачів, яким більше 18 років.

5.2 Кілька умов

SELECT * FROM users WHERE age > 18 AND name = 'Іван';

Тут запис має одночасно задовольняти дві умови:
— вік більше 18
— ім’я Іван

5.3 Інші приклади

SELECT * FROM users WHERE age = 20;
SELECT * FROM users WHERE age <> 18;

<> означає “не дорівнює”.

Порада: WHERE — це одна з найважливіших частин SQL. Без неї запити майже завжди будуть занадто грубими і незручними.

📊 6. Сортування: ORDER BY

Команда ORDER BY дозволяє впорядкувати результати запиту.

6.1 Сортування за зростанням

SELECT * FROM users ORDER BY age ASC;

ASC означає “по зростанню”.

6.2 Сортування за спаданням

SELECT * FROM users ORDER BY age DESC;

DESC означає “по спаданні”.

6.3 Чому це корисно?

Сортування дуже часто потрібно в реальних задачах:
— показати найстарших користувачів
— вивести товари від дешевших до дорожчих
— показати найновіші записи першими

✍ 7. Оновлення даних: UPDATE

Якщо дані в таблиці треба змінити, використовують команду UPDATE.

7.1 Приклад оновлення

UPDATE users SET age = 25 WHERE id = 1;

Тут ми змінюємо вік користувача з id = 1 на 25.

7.2 Чому WHERE тут критично важливий?

Бо без WHERE зміна застосовується до всіх записів таблиці.

UPDATE users SET age = 25;

Такий запит змінить вік усім користувачам, а це вже може бути великою помилкою.

Увага: у UPDATE майже завжди треба уважно перевіряти умову в WHERE.

❌ 8. Видалення даних: DELETE

Команда DELETE видаляє записи з таблиці.

8.1 Видалення одного запису

DELETE FROM users WHERE id = 1;

Тут буде видалений тільки запис з id = 1.

8.2 Видалення всіх записів

DELETE FROM users;

Такий запит видалить усі рядки таблиці.

Увага: як і в UPDATE, у DELETE дуже небезпечно забути WHERE.

🔑 9. Ключі: PRIMARY KEY і FOREIGN KEY

У базах даних дуже важливо вміти однозначно визначати записи і пов’язувати таблиці між собою. Для цього використовують ключі.

9.1 PRIMARY KEY

PRIMARY KEY — це головний ключ таблиці. Він унікально визначає кожен рядок.

CREATE TABLE users ( id INT PRIMARY KEY, name VARCHAR(50), age INT );

Тут поле id є унікальним ідентифікатором користувача.

9.2 FOREIGN KEY

FOREIGN KEY — це зовнішній ключ, який зв’язує одну таблицю з іншою.

CREATE TABLE orders ( id INT PRIMARY KEY, user_id INT, product VARCHAR(50) );

Поле user_id може зберігати id користувача з таблиці users. Саме так будуються зв’язки між таблицями.

9.3 Чому ключі важливі?

Бо без них база даних перетворюється просто на набір окремих таблиць без логічних зв’язків. А в реальних системах усе пов’язано: користувачі, замовлення, товари, оцінки, викладачі, групи.

🔗 10. Об’єднання таблиць: JOIN

JOIN — це одна з найважливіших тем у SQL. Вона дозволяє об’єднувати дані з кількох таблиць в один результат.

Наприклад, у тебе є:
— таблиця users
— таблиця orders
і ти хочеш побачити не просто замовлення, а ще й ім’я користувача, який це замовлення зробив.

10.1 Приклад JOIN

SELECT users.name, orders.product FROM users JOIN orders ON users.id = orders.user_id;

Тут:
users.name — беремо ім’я з таблиці users
orders.product — беремо товар з таблиці orders
ON users.id = orders.user_id — умова, по якій таблиці поєднуються

10.2 Чому JOIN такий важливий?

Бо в реальних базах даних інформація зазвичай розбита на кілька таблиць. Якщо не вміти робити JOIN, то працювати з реальною базою буде дуже важко.

Пам’ятай: JOIN — це вже перехід від дуже базового SQL до більш реального і практичного рівня.

📈 11. GROUP BY і агрегатні функції

Іноді треба не просто побачити окремі рядки, а порахувати статистику: скільки записів, який середній вік, яке максимальне значення. Для цього використовують агрегатні функції і GROUP BY.

11.1 COUNT

SELECT COUNT(*) FROM users;

Показує кількість записів у таблиці.

11.2 AVG, MAX, MIN, SUM

SELECT AVG(age) FROM users;
SELECT MAX(age) FROM users;
SELECT MIN(age) FROM users;
SELECT SUM(age) FROM users;

11.3 GROUP BY

GROUP BY групує записи за певним полем.

SELECT age, COUNT(*) FROM users GROUP BY age;

Тут ми групуємо користувачів за віком і рахуємо, скільки людей має кожен вік.

11.4 Чому це важливо?

Такі запити дуже потрібні для аналітики, звітів і статистики. Наприклад:
— скільки студентів у кожній групі
— яка середня оцінка
— скільки замовлень у кожного клієнта

⚠ 12. Типові помилки новачків

  • Забутий WHERE у UPDATE або DELETE — може зіпсувати всі записи.
  • Неправильна назва таблиці або поля — запит просто не виконається.
  • Плутанина з типами даних — число записують як текст або навпаки.
  • Неправильний JOIN — таблиці об’єднуються не по тих полях.
  • Проблеми з лапками — текстові значення треба правильно оформляти.
  • Неправильний порядок логіки — наприклад, спроба робити складний запит, не розуміючи простого SELECT.
Порада: у SQL дуже важливо спочатку думати, які саме дані ти хочеш отримати, а вже потім писати запит.

📚 13. Практичні задачі для закріплення

  2. Виведи всі записи.
  3. Виведи тільки імена та вік.

Після теми «WHERE і ORDER BY»

  1. Виведи студентів, яким більше 18.
  2. Відсортуй студентів за віком.
  3. Виведи тільки одного користувача по id.

Після теми «UPDATE і DELETE»

  1. Зміни вік одного студента.
  2. Видали один запис по id.

Після теми «JOIN і GROUP BY»

  1. Створи таблиці users і orders.
  2. Зв’яжи їх через user_id.
  3. Виведи ім’я користувача і його товар через JOIN.
  4. Порахуй кількість користувачів у кожній віковій групі через GROUP BY.
