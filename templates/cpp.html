Курс: C++

Повний розбір від історії створення до керування пам'яттю

🎯 Для кого цей курс?

Цей курс створений для повних новачків, які ще майже не програмували або тільки починають знайомство з C++. Матеріал побудований так, щоб людина крок за кроком зрозуміла базу і навчилась писати прості програми самостійно.

Після проходження курсу ти зможеш:

  • створювати прості програми на C++;
  • працювати зі змінними, умовами, циклами та функціями;
  • зчитувати дані з клавіатури та виводити результат на екран;
  • писати прості алгоритми для задач початкового рівня;
  • розуміти основи пам’яті, вказівників і посилань.
Головна ціль курсу: не просто дати теорію, а довести людину до моменту, коли вона вже може сама написати свою першу нормальну програму.

C++ був розроблений Б'ярне Страуструпом у Bell Labs у 1979 році. Спочатку проект мав назву "C with Classes". Автор хотів поєднати швидкість мови C з можливостями високорівневого моделювання (класами).

Де сьогодні використовують C++?

  • Gamedev: Unreal Engine написаний на C++. Майже всі AAA-ігри використовують цю мову для швидкості.
  • ОС та драйвери: Ядра Windows, macOS та частини Linux.
  • Фінанси: Торгові роботи на біржах, де мілісекунди мають значення.
  • Браузери: Двигун Google Chrome (V8) базується на C++.

📂 1. Вступ: Як налаштувати все для роботи

Перш ніж писати код, треба зрозуміти одну річ: комп'ютер не розуміє англійські слова на кшталт cout. Йому потрібен Компілятор — це така програма-перекладач, яка перетворить ваш текст у файл .exe.

Крок 1: Вибір «робочого місця»

Для навчання на Windows ми обираємо Visual Studio Community. Це безкоштовно, і там вже є все необхідне в одному пакеті.

1. Завантаження: Зайдіть у Google, введіть "Visual Studio Community" і завантажте інсталятор з офіційного сайту Microsoft.
2. Встановлення (Важливо!): Коли відкриється вікно з вибором компонентів, знайдіть пункт "Розробка класичних програм на C++" (Desktop development with C++). Поставте там галочку. Без цього компілятор не встановиться, і код не працюватиме. Натисніть "Інсталювати".
3. Створення проекту: Запустіть програму -> Створити новий проект -> Оберіть "Пустий проект C++" -> Дайте йому назву (наприклад, MyFirstApp).
4. Додавання файлу: У правій колонці (Провідник рішень) клацніть правою кнопкою на папку "Файли вихідного коду" -> Додати -> Новий елемент -> Оберіть файл .cpp.
Що робити, якщо у мене слабкий комп? Якщо Visual Studio гальмує, встановіть VS Code. Але пам'ятайте: VS Code — це просто редактор. До нього треба окремо встановити компілятор (наприклад, MinGW), що трохи складніше для новачка.
Як це працює простою мовою: Ви пишете код -> Натискаєте кнопку "Пуск" (F5) -> Препроцесор збирає всі шматочки до купи -> Компілятор перекладає це на мову процесора -> Лінкувальник робить готовий файл, який можна запустити.

⌨ 2. Основний синтаксис та введення/виведення

Будь-яка програма на C++ — це набір інструкцій. Давайте розберемо по цеглинках, як вона будується:

1. Підключення «інструментів» (#include)
Щоб програма могла щось писати на екрані, нам потрібна бібліотека iostream (Input/Output Stream). Без неї комп'ютер не знатиме, що таке «вивід». Також ми додаємо string, щоб працювати з іменами та текстом.
2. Головна функція (int main)
Це «серце» програми. Все, що написано всередині фігурних дужок { ... }, буде виконуватися комп'ютером по черзі.
3. Виведення тексту (std::cout)
Символ cout відправляє текст на екран. Стрілочки << вказують напрямок — ми «штовхаємо» текст до екрана.
4. Введення даних (std::cin та getline)
cin дозволяє користувачу щось надрукувати. Але якщо ми хочемо зчитати ціле речення з пробілами, ми використовуємо команду std::getline.

Приклад правильного коду:

#include <iostream> #include <string> int main() { std::string userName; std::cout << "Як вас звати? "; std::getline(std::cin, userName); std::cout << "Привіт, " << userName << "!" << std::endl; return 0; }
std::endl — це команда завершення рядка. Вона каже програмі: «Перейди на наступний рядок і негайно покажи все, що накопичилося в пам'яті».

📝 3. Коментарі в коді

Коментарі потрібні для пояснення коду. Їх читає програміст, але компілятор їх ігнорує. Це дуже корисно, коли ти повертаєшся до свого коду через кілька днів і хочеш швидко зрозуміти, що саме тут відбувається.

Однорядковий коментар

// Це коментар на один рядок int age = 18;

Багаторядковий коментар

/* Це багаторядковий коментар. Тут можна описати цілий блок коду або пояснення до програми. */
Порада: не треба коментувати кожен рядок підряд. Коментар має пояснювати сенс, а не дублювати очевидне.

🔧 4. Змінні та ініціалізація

Змінна — це іменована область пам’яті, де зберігається значення. Простими словами: це коробка, в яку ми кладемо дані.

Оголошення змінної

int age; double price; char letter;

Ініціалізація змінної

Ініціалізація — це коли ти одразу даєш змінній значення під час створення.

int age = 18; double price = 99.99; char letter = 'A';

Оголосити і присвоїти пізніше

int year; year = 2025;

Правила назв змінних

  • назва повинна бути зрозумілою: studentAge, totalPrice;
  • не можна починати назву з цифри;
  • не можна використовувати пробіли;
  • краще не робити назви типу a, x1, якщо це не дуже коротка задача.
Міні-вправа: створи змінні для імені, віку, росту і виведи їх на екран.

📊 5. Типи даних та оператори

У C++ вибір типу даних — це не просто назва, це команда комп’ютеру виділити певну кількість байтів у пам'яті. Якщо обрати замалу "коробку", дані в неї не влізуть.

5.1 Основні типи даних та їхні розміри

  • bool (1 байт): Логічний перемикач. Зберігає лише true або false.
  • char (1 байт): Зберігає один символ. Пишеться в одинарних лапках: 'A'.
  • int (4 байти): Цілі числа. Основний тип для лічильників, віку, кількості.
  • double (8 байт): Дробові числа з високою точністю.
  • float (4 байти): Дробові числа, але менш точні, ніж double.
int soldiers = 50; double price = 450.75; char rank = 'S'; bool isDead = false; int result = 10 / 3; double realResult = 10.0 / 3.0;

5.2 Арифметичні оператори

Оператор Що робить Приклад
+ / - Додавання та віднімання 10 + 5 = 15
* / / Множення та ділення 20 * 2 = 40
% Остача від ділення 10 % 3 = 1
int x = 10; int y = 3; int sum = x + y; int diff = x - y; int prod = x * y; int quot = x / y; int rem = x % y; x++; y--;

5.3 Оператори порівняння

Ці оператори потрібні, щоб порівнювати значення. Вони дуже важливі для if, while та інших умов.

Оператор Що означає Приклад
== дорівнює a == b
!= не дорівнює a != b
> більше a > b
< менше a < b
>= більше або дорівнює a >= b
<= менше або дорівнює a <= b
int age = 18; if (age >= 18) { std::cout << "Доступ дозволено"; }

5.4 Логічні оператори

Оператор Назва Для чого потрібен?
&& Логічне "І" Результат true, якщо обидві умови істинні.
|| Логічне "АБО" Результат true, якщо хоча б одна умова істинна.
! Логічне "НЕ" Інвертує значення.
int ageUser = 20; bool hasMoney = true; bool canBuy = (ageUser >= 18) && (hasMoney == true);

🔄 6. Керування потоком: умови та цикли

Керування потоком означає, що програма може не просто виконувати команди зверху вниз, а приймати рішення і повторювати дії. Саме завдяки цьому програми стають “розумними”: вони можуть перевіряти умови, реагувати на введення користувача і багато разів виконувати однакові операції.

6.1 Умовний оператор if, else if, else

Це основа будь-якої логіки в програмуванні. Програма перевіряє умову в круглих дужках. Якщо умова істинна (true), виконується один блок коду. Якщо ні — програма переходить до іншого блоку.

if — якщо умова істинна
else if — інакше якщо попередня умова не спрацювала, але ця правильна
else — інакше, якщо нічого вище не підійшло

int score = 85; if (score >= 90) { std::cout << "Відмінно!" << std::endl; } else if (score >= 70) { std::cout << "Добре!" << std::endl; } else { std::cout << "Потрібно підтягнути знання." << std::endl; }

У цьому прикладі програма перевіряє оцінку. Якщо вона 90 або більше — виводиться "Відмінно". Якщо менше 90, але 70 або більше — "Добре". Якщо жодна умова не підійшла — спрацює else.

6.2 Оператор switch

switch зручний тоді, коли одна змінна може мати кілька конкретних значень. Це більш охайний варіант, ніж писати багато if підряд.

switch — що перевіряємо
case — можливе значення
break — зупинка після виконання потрібного варіанта
default — виконується, якщо жоден варіант не підійшов

int day = 2; switch (day) { case 1: std::cout << "Понеділок"; break; case 2: std::cout << "Вівторок"; break; default: std::cout << "Інший день"; break; }

Тут програма дивиться на значення змінної day. Якщо воно дорівнює 2, буде виведено "Вівторок". break дуже важливий, бо без нього програма може піти далі в наступні case.

6.3 Цикл for

for використовують тоді, коли ти точно знаєш, скільки разів треба повторити дію. Наприклад, вивести числа від 1 до 10 або пройтися по елементах масиву.

У циклі for є три частини:

  • початок — створення лічильника
  • умова — доки цикл має працювати
  • крок — як змінюється лічильник після кожного повтору
for (int i = 1; i <= 5; i++) { std::cout << "Крок номер: " << i << std::endl; }

У цьому прикладі спочатку створюється змінна i = 1. Потім перевіряється умова i <= 5. Поки вона істинна, код виконується. Після кожного повтору i збільшується на 1.

6.4 Цикл while

while підходить тоді, коли ми не знаємо точно, скільки буде повторів. Цикл працює доти, доки умова істинна.

Це називають циклом з передумовою, бо умова перевіряється до виконання коду.

int energy = 3; while (energy > 0) { std::cout << "Гравець біжить... Енергія: " << energy << std::endl; energy--; }

Тут цикл буде працювати, поки енергія більша за 0. Після кожного повтору ми зменшуємо значення на 1. Коли енергія стане 0, умова стане хибною і цикл завершиться.

6.5 Цикл do-while

do-while схожий на while, але є одна важлива різниця: код всередині нього гарантовано виконається хоча б один раз. Тому що перевірка умови йде вже після виконання команд.

int x = 10; do { std::cout << "Це повідомлення з'явиться хоча б раз" << std::endl; } while (x < 5);

Навіть якщо умова x < 5 відразу неправильна, повідомлення все одно виведеться один раз, бо спочатку виконується тіло циклу, а вже потім перевіряється умова.

Порада: якщо в циклі умова ніколи не стане хибною, програма зациклиться. Тому завжди перевіряй, чи змінюється змінна всередині циклу.
Практика:
  • перевірити, чи число парне;
  • знайти більше з двох чисел;
  • вивести числа від 1 до 10;
  • порахувати суму чисел від 1 до n.

💬 7. Рядки та робота з текстом

У програмуванні дуже часто треба працювати не тільки з числами, а й з текстом: іменами, містами, повідомленнями, паролями, реченнями. Для цього в C++ використовується тип std::string.

Рядок — це набір символів, з якими можна працювати як з одним цілим значенням. Наприклад, зберегти ім’я користувача, порахувати довжину слова або взяти окрему букву з тексту.

7.1 Створення рядка

Щоб працювати з текстом, потрібно підключити бібліотеку string. Після цього можна створити змінну типу std::string і записати в неї текст.

#include <string> std::string name = "Vitalik";

Тут у змінній name зберігається слово "Vitalik". На відміну від char, який зберігає тільки один символ, string зберігає ціле слово або речення.

7.2 Об'єднання рядків

Рядки можна з’єднувати між собою за допомогою оператора +. Це зручно для створення повідомлень і привітань.

std::string firstName = "Віталік"; std::string text = "Привіт, " + firstName;

У результаті в змінній text буде збережено: Привіт, Віталік.

7.3 Довжина рядка

Іноді треба дізнатись, скільки символів у слові. Для цього використовують метод length().

std::string word = "programming"; std::cout << word.length();

Ця команда поверне кількість символів у слові programming.

7.4 Доступ до окремих символів

У рядку можна звертатися до конкретного символу за індексом. Важливо пам’ятати: індексація починається з 0.

std::string city = "Lviv"; std::cout << city[0]; // L

Тобто:
city[0] — перша буква
city[1] — друга
city[2] — третя і так далі.

7.5 Зчитування рядка з пробілами

Якщо користувач вводить одне слово, можна використати cin. Але якщо треба зчитати ціле речення з пробілами, використовують getline.

std::string fullName; std::getline(std::cin, fullName);

Так програма зчитає повністю все, що введе користувач, навіть якщо там буде ім’я та прізвище.

Практика:
  • зчитати ім’я користувача і вивести привітання;
  • порахувати довжину слова;
  • вивести перший і останній символ рядка.

🗃 8. Масиви

Масив — це набір кількох значень одного типу, які зберігаються під одним ім’ям. Це зручно, коли потрібно працювати не з одним числом, а одразу з групою чисел.

Наприклад, якщо треба зберегти 5 оцінок студента, не обов’язково створювати 5 окремих змінних. Можна створити один масив і звертатися до кожного елемента за його індексом.

8.1 Створення масиву

При створенні масиву ми вказуємо тип даних, назву і кількість елементів у квадратних дужках.

int nums[5] = {10, 20, 30, 40, 50};

Тут створено масив із 5 цілих чисел. Значення в ньому лежать по порядку.

8.2 Індекси елементів

Кожен елемент масиву має свій номер — індекс. І дуже важливо запам’ятати: перший елемент має індекс 0, а не 1.

std::cout << nums[0]; // 10 std::cout << nums[2]; // 30

Тобто:
nums[0] — перший елемент
nums[1] — другий
nums[2] — третій

8.3 Перебір масиву циклом

Дуже часто масив проходять циклом for, щоб не звертатися до кожного елемента вручну.

for (int i = 0; i < 5; i++) { std::cout << nums[i] << std::endl; }

Тут змінна i спочатку дорівнює 0, потім 1, 2, 3, 4. На кожному кроці ми беремо елемент масиву з таким індексом і виводимо його.

8.4 Зміна значення елемента

Елементи масиву можна змінювати, звертаючись до них по індексу.

nums[1] = 99;

Тепер другий елемент масиву вже не 20, а 99.

8.5 Чому масиви важливі?

Масиви — це одна з базових структур у програмуванні. Вони потрібні для списків чисел, оцінок, результатів, координат та багатьох інших задач. Без розуміння масивів буде важко переходити до складніших тем.

Увага: не можна виходити за межі масиву. Якщо масив має 5 елементів, то правильні індекси — від 0 до 4. Звернення до nums[10] може викликати помилку.
Практика:
  • створи масив із 5 чисел;
  • виведи всі елементи циклом;
  • знайди суму всіх елементів;
  • знайди найбільше число в масиві.

📦 9. Функції: створення, параметри та прототипи

Функція — це окремий блок коду, який виконує одну конкретну задачу. Простими словами: ти один раз описуєш дію, а потім можеш викликати її стільки разів, скільки потрібно.

Без функцій програма дуже швидко стає довгою, заплутаною і незручною. Якщо якийсь шматок коду повторюється кілька разів — це знак, що його краще винести у функцію.

Навіщо потрібні функції?

  • ✅ не треба дублювати один і той самий код
  • ✅ програма стає чистішою і зрозумілішою
  • ✅ легше виправляти помилки
  • ✅ зручно розбивати велику задачу на маленькі частини

9.1 Загальна будова функції

У кожної функції є тип результату, назва і параметри.

тип_результату назва_функції(параметри) { // код функції }

тип_результату — що функція повертає
назва — як ти її будеш викликати
параметри — які дані вона отримує для роботи

Якщо функція нічого не повертає, тоді пишуть void.

9.2 Функція без параметрів

Це найпростіший варіант. Така функція просто виконує код, коли її викликають.

#include <iostream> void sayHi() { std::cout << "Привіт з функції!" << std::endl; } int main() { sayHi(); return 0; }

Тут функція sayHi() не приймає жодних даних і просто виводить повідомлення. У main() ми її викликаємо, і програма виконує цей блок коду.

9.3 Функція з параметрами

Параметри потрібні тоді, коли функція має працювати з різними значеннями. Наприклад, не просто “додати 5 і 7”, а вміти додавати будь-які два числа.

int add(int a, int b) { return a + b; } int main() { int result = add(5, 7); std::cout << result; }

Тут:
a і b — параметри функції
return повертає результат назад
add(5, 7) — виклик функції з конкретними значеннями

9.4 Оператор return

return завершує роботу функції і повертає результат туди, звідки її викликали.

int square(int x) { return x * x; }

Як тільки спрацював return, функція одразу закінчується.

9.5 Прототипи функцій

C++ читає код зверху вниз. Якщо функція написана нижче за main(), компілятор ще не знає, що вона існує. Для цього використовують прототип — короткий запис функції без тіла.

#include <iostream> int add(int x, int y); int main() { std::cout << add(3, 4); } int add(int x, int y) { return x + y; }

Прототип каже компілятору: “така функція буде далі, просто запам’ятай її назву, параметри і тип повернення”.

Запам’ятай: функції — це один із найважливіших інструментів у програмуванні. Саме вони роблять код не хаотичним, а структурованим.

🧠 10. Основи пам’яті: вказівники та посилання

У C++ кожна змінна зберігається в оперативній пам’яті комп’ютера. Це означає, що у кожного значення є не тільки саме число або текст, а ще й адреса в пам’яті, де це значення лежить.

Розуміння адрес, вказівників і посилань — дуже важливе, бо це одна з головних особливостей C++. Саме через це C++ вважається потужною мовою, яка дає пряміший доступ до пам’яті, ніж багато інших мов.

10.1 Адреса змінної

Щоб дізнатись адресу змінної, використовують оператор &.

int x = 10; std::cout << "Адреса змінної x: " << &x << std::endl;

Тут &x означає: “покажи адресу, де в пам’яті лежить змінна x”. Саме значення змінної — це 10, а адреса — це місце, де це 10 зберігається.

10.2 Вказівники

Вказівник — це спеціальна змінна, яка зберігає не саме значення, а адресу іншої змінної. Тобто вказівник “показує”, де лежать дані.

int money = 100; int* ptr = &money;

Тут:
money — звичайна змінна зі значенням 100
ptr — вказівник
&money — адреса змінної money
int* означає: вказівник на змінну типу int

10.3 Робота з вказівником

Коли ми пишемо просто ptr, ми бачимо адресу. А коли пишемо *ptr, ми отримуємо значення, що лежить за цією адресою.

std::cout << ptr << std::endl; std::cout << *ptr << std::endl;

У першому рядку виведеться адреса. У другому — значення 100, бо саме воно лежить за адресою, яку зберігає вказівник.

10.4 Зміна значення через вказівник

Через вказівник можна не тільки дивитися значення, а й змінювати його.

*ptr = 200; std::cout << money;

Після цього змінна money вже матиме значення 200. Тобто ми змінили її не напряму, а через адресу в пам’яті.

10.5 Посилання

Посилання — це інше ім’я для вже існуючої змінної. Воно не зберігає окрему адресу, як вказівник, а просто дає друге ім’я тій самій змінній.

int a = 50; int &b = a; b += 10; std::cout << a;

Тут b — це посилання на a. Якщо змінити b, зміниться і a, бо це фактично одне й те саме значення під різними іменами.

10.6 Передача у функцію за посиланням

За замовчуванням у функцію передається копія змінної. Це означає, що зміни всередині функції не вплинуть на оригінал. Але якщо передати змінну за посиланням, функція зможе змінити її напряму.

void add(int &x) { x += 10; }

У цьому випадку функція працює не з копією, а з реальною змінною. Це економить пам’ять і дозволяє змінювати початкове значення без return.

Пам’ятай: для новачка посилання зазвичай простіші та безпечніші, ніж вказівники. Але вказівники треба розуміти, бо без них важко перейти до складніших тем C++.

⚠ 11. Типові помилки новачків

У C++ помилки — це нормальна частина навчання. Головне — вміти їх бачити і розуміти.

  • Забутий ;
    У C++ більшість інструкцій закінчується крапкою з комою.
  • = замість ==
    = — це присвоєння, а == — порівняння.
  • Не підключена бібліотека
    Якщо не написати #include <iostream>, то cout не працюватиме.
  • Забув std::
    Наприклад: std::cout, std::cin, std::string.
  • Нескінченний цикл
    Коли умова завжди true і змінна в циклі не змінюється.
  • Цілочисельне ділення
    5 / 2 дає 2, а не 2.5.
  • Вихід за межі масиву
    Неправильний індекс може зламати логіку програми.
  • Неініціалізована змінна
    Іноді вона містить сміттєве значення.
Порада: якщо програма не працює, перевір спочатку найпростіші речі: дужки, крапку з комою, назви змінних і умови.

📚 12. Практичні задачі для закріплення

Після теми «Змінні»

  1. Створи змінні для імені, віку та міста.
  2. Виведи їх у гарному вигляді на екран.
  3. Створи програму, яка рахує суму двох чисел.

Після теми «Умови»

  1. Перевірити, чи людина повнолітня.
  2. Знайти більше з двох чисел.
  3. Перевірити, чи число парне чи непарне.

Після теми «Цикли»

  1. Вивести числа від 1 до 10.
  2. Знайти суму чисел від 1 до n.
  3. Вивести таблицю множення для числа.

Після теми «Масиви»

  1. Вивести всі елементи масиву.
  2. Знайти найбільший елемент.
  3. Порахувати середнє значення елементів.
