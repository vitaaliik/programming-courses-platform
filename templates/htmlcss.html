Курс: HTML/CSS

Повний вступ у веб-розробку: структура сторінки через HTML та оформлення через CSS.

🎯 Для кого цей курс?

Цей курс створений для початківців, які хочуть з нуля зрозуміти, як створюються веб-сторінки. Матеріал підібраний так, щоб людина поступово навчилась будувати структуру сторінки, оформлювати її стилями та збирати прості, але вже нормальні сайти.

Після проходження курсу ти зможеш:

  • розуміти, як побудований HTML-документ;
  • створювати тексти, списки, посилання, зображення та блоки;
  • оформлювати сторінку через CSS;
  • працювати з відступами, рамками, кольорами та шрифтами;
  • будувати прості макети через Flexbox.
Головна мета курсу: дати тобі реальну базу, після якої ти зможеш самостійно зробити просту, акуратну веб-сторінку.

📜 Історія та Призначення

HTML (HyperText Markup Language) був створений Тімом Бернерсом-Лі в 1991 році як основа для побудови веб-сторінок. Його задача — описати структуру сторінки: де заголовок, де текст, де список, де картинка, де посилання.

CSS (Cascading Style Sheets) з’явився пізніше, щоб відповідати за вигляд сторінки: кольори, відступи, шрифти, розміри, блоки, розташування елементів.

Де використовуються HTML і CSS?

  • Веб-сайти: будь-яка сторінка в інтернеті починається з HTML та CSS.
  • Frontend-розробка: React, Vue, Angular теж працюють поверх HTML та CSS.
  • Лендінги та портфоліо: прості сайти, візитки, сторінки курсів, магазини.
  • Email-розсилки: верстка листів теж часто базується на HTML і CSS.
Важливо: HTML і CSS — це не повноцінні мови програмування. HTML відповідає за структуру, а CSS — за оформлення. Але без них веб-розробка неможлива.

📅 План Навчання (Основи)

  1. HTML: структура документа, основні теги.
  2. Текстові елементи: заголовки, абзаци, списки.
  3. Посилання, зображення, блоки та контейнери.
  4. CSS: синтаксис, селектори, способи підключення.
  5. Кольори, шрифти, фон, розміри.
  6. Box Model: margin, border, padding, content.
  7. Display, block, inline, inline-block.
  8. Flexbox для побудови макетів.
  9. Типові помилки новачків.
  10. Практичні задачі та міні-проєкти.

📂 1. Базова структура HTML-документа

Кожна HTML-сторінка має стандартну структуру. Вона допомагає браузеру зрозуміти, що саме він відкрив і як це відображати.

1.1 Основні частини документа

У HTML найчастіше ти будеш бачити такі основні частини:

  • <!DOCTYPE html> — каже браузеру, що це HTML5-документ;
  • <html> — кореневий тег усього документа;
  • <head> — службова частина: метадані, назва вкладки, підключення CSS;
  • <body> — все, що реально бачить користувач на сторінці.
<!DOCTYPE html> <html lang="uk"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Мій Сайт</title> </head> <body> <h1>Заголовок сторінки</h1> <p>Це мій перший HTML-документ.</p> </body> </html>

У цьому прикладі браузер бачить повністю готовий HTML-документ із заголовком сторінки та абзацом тексту.

Пам’ятай: усе, що ти хочеш показати користувачу на сторінці, має бути всередині <body>.

⌨ 2. Текстові елементи: заголовки, абзаци та списки

HTML має багато тегів, але новачку спочатку треба зрозуміти найважливіші. Це теги для тексту, бо майже будь-яка сторінка починається саме з них.

2.1 Заголовки

Для заголовків використовуються теги від <h1> до <h6>. Найважливіший заголовок сторінки — це зазвичай <h1>.

<h1>Головний заголовок</h1> <h2>Підзаголовок</h2> <h3>Ще менший заголовок</h3>

2.2 Абзаци

Для звичайного тексту використовують тег <p>.

<p>Це абзац тексту на сторінці.</p>

2.3 Списки

У HTML є два основних види списків:

  • <ul> — маркований список;
  • <ol> — нумерований список.
<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul> <ol> <li>Відкрити редактор</li> <li>Створити файл</li> <li>Написати код</li> </ol>

Список завжди складається з контейнера (ul або ol) і пунктів li.

🔗 3. Посилання, зображення та блоки

Після тексту наступні важливі елементи — це посилання, картинки і блоки, з яких будується майже будь-яка сторінка.

3.1 Посилання

Для переходу на іншу сторінку або сайт використовують тег <a>.

<a href="https://example.com">Перейти на сайт</a>

Атрибут href вказує адресу, куди веде посилання.

3.2 Зображення

Для показу картинки використовують тег <img>.

<img src="image.jpg" alt="Опис зображення">

Тут:
src — шлях до файлу
alt — текстовий опис, якщо картинка не завантажиться

3.3 Блоки через div

Тег <div> — це універсальний контейнер для групування елементів. Його дуже часто використовують для побудови структури сторінки.

<div> <h2>Назва блоку</h2> <p>Текст усередині блоку</p> </div>

Сам по собі div нічого особливого не показує, але він дуже важливий для верстки та стилізації.

🎨 4. CSS: синтаксис і способи підключення

Якщо HTML відповідає за структуру, то CSS відповідає за вигляд сторінки. Саме через CSS ми задаємо кольори, шрифти, відступи, рамки, розміри та розташування елементів.

4.1 Базовий синтаксис CSS

CSS складається з селектора, властивості та значення.

h1 { color: blue; font-size: 24px; }

Тут:
h1 — селектор
color — властивість
blue — значення

4.2 Способи підключення CSS

CSS можна підключити трьома способами:

  1. вбудовано в тег через атрибут style;
  2. всередині документа через тег <style>;
  3. окремим файлом через <link>.
<link rel="stylesheet" href="style.css">

Найкращий варіант для нормального сайту — окремий CSS-файл.

4.3 Селектори

Через селектори CSS розуміє, до якого елемента застосувати стиль.

h1 { color: red; } .my-text { background-color: #f0f0f0; } #main-title { font-size: 30px; }

Тут:
селектор h1 звертається до всіх заголовків h1
.my-text — до класу
#main-title — до id

🌄 5. Основи CSS: кольори, шрифти, фон і розміри

Після того як ти зрозумів синтаксис CSS, треба перейти до найуживаніших властивостей. Саме вони найчастіше використовуються майже на будь-якій сторінці, бо відповідають за те, як виглядає текст, блоки і фон.

Якщо HTML створює структуру сторінки, то CSS робить її візуально зрозумілою і красивою. Саме через ці базові властивості ти керуєш тим, який буде колір тексту, який шрифт використовуватиметься, який фон матиме блок і яких розмірів він буде.

Ці властивості здаються простими, але насправді вони є основою майже всього оформлення. Без них сторінка виглядала б як звичайний “сухий” текст без стилю.

5.1 Колір тексту

Щоб змінити колір тексту, використовують властивість color.

p { color: green; }

Тепер усі абзаци <p> будуть зеленого кольору. Колір можна задавати словами, через HEX-коди, RGB та інші формати.

5.2 Фон елемента

Щоб задати фон елементу, використовують background-color.

div { background-color: #f5f5f5; }

Це часто використовують для карток, секцій, кнопок і контейнерів, щоб вони візуально відділялися від решти сторінки.

5.3 Розмір шрифту

Властивість font-size відповідає за розмір тексту. Через неї можна робити заголовки більшими, а другорядний текст — меншим.

h1 { font-size: 32px; }

Тут заголовок h1 буде мати розмір 32 пікселі.

5.4 Шрифт

Щоб змінити сам вигляд букв, використовують властивість font-family. Вона дозволяє вибрати шрифт для елемента або навіть для всієї сторінки.

body { font-family: Arial, sans-serif; }

У цьому прикладі для всієї сторінки задається шрифт Arial. Якщо він недоступний, браузер спробує використати будь-який інший шрифт без засічок (sans-serif).

5.5 Розміри елемента

Щоб задати конкретні розміри блоку, використовують width і height. Це особливо корисно для карток, контейнерів, секцій та зображень.

.box { width: 200px; height: 100px; }

Тут елемент з класом box матиме ширину 200 пікселів і висоту 100 пікселів.

5.6 Чому це важливо?

Саме ці властивості формують перше враження від сторінки. Навіть якщо структура зроблена правильно, без кольорів, шрифтів, фону і нормальних розмірів сайт буде виглядати сиро і неакуратно.

Тому ці CSS-властивості — це не просто дрібниці, а справжня основа оформлення будь-якого веб-інтерфейсу.

Практика:
  • зміни колір тексту в абзаці;
  • додай фоновий колір блоку;
  • зміни розмір заголовка;
  • застосуй інший шрифт до всієї сторінки;
  • створи блок із заданою шириною та висотою.

📦 6. Box Model: відступи, рамки та простір елемента

Кожен HTML-елемент у CSS можна уявити як прямокутний блок. У цього блоку є свій вміст, внутрішні відступи, рамка і зовнішні відступи. Це називається Box Model, або блокова модель.

Розуміння Box Model дуже важливе, бо саме воно пояснює, чому елемент займає певне місце на сторінці, чому між блоками є відстань і чому інколи розміри виглядають “не такими, як очікувалось”.

6.1 Частини Box Model

  • content — сам вміст елемента;
  • padding — внутрішній відступ між контентом і рамкою;
  • border — рамка навколо елемента;
  • margin — зовнішній відступ між елементом і сусідніми блоками.

6.2 Приклад Box Model

.box { width: 200px; height: 100px; padding: 15px; border: 5px solid red; margin: 20px; }

У цьому прикладі:
width і height задають розміри контенту
padding додає внутрішній простір
border створює рамку
margin додає простір зовні

6.3 Чому це важливо?

Без розуміння Box Model дуже важко нормально верстати сторінку. Саме через цю модель ти контролюєш відстані між блоками, розміри карток, кнопок, контейнерів і загальну акуратність сторінки.

Порада: якщо елемент виглядає “занадто великим” або “з'їжджає”, дуже часто причина саме в padding, border або margin.
Практика:
  • створи блок із текстом;
  • додай йому рамку;
  • зроби внутрішній і зовнішній відступ;
  • зміни ширину та висоту блоку.

📑 7. Display: block, inline та inline-block

Ще одна дуже важлива тема у верстці — це властивість display. Саме вона визначає, як елемент поводиться на сторінці і як він займає простір.

Якщо сказати просто:
— одні елементи займають весь рядок
— інші займають тільки стільки місця, скільки їм треба
— деякі поєднують властивості обох варіантів

7.1 display: block

Блоковий елемент займає всю доступну ширину рядка і починається з нового рядка.

div { display: block; }

Приклади блокових елементів: div, p, h1, section.

7.2 display: inline

Inline-елемент займає тільки ту ширину, яка потрібна для його вмісту, і не переноситься на новий рядок сам по собі.

span { display: inline; }

Приклади inline-елементів: span, a, strong.

7.3 display: inline-block

inline-block — це проміжний варіант. Елемент стоїть у рядку, але при цьому йому можна задавати ширину, висоту, margin і padding зручніше, ніж звичайному inline-елементу.

.card { display: inline-block; width: 200px; padding: 15px; }

Такий режим часто використовували для карток, меню та блоків ще до масового використання Flexbox.

7.4 Чому це важливо?

Без розуміння display дуже складно зрозуміти, чому елементи стоять саме так, а не інакше. Це одна з базових тем для нормальної верстки.

Практика:
  • створи блок div і подивись, як він займає рядок;
  • створи кілька span і подивись, як вони стоять в одному рядку;
  • зроби картку через inline-block.

🧩 8. Flexbox: сучасний спосіб розташування елементів

Flexbox — це один із найзручніших сучасних інструментів для побудови макетів у CSS. Він дозволяє легко вирівнювати елементи по горизонталі, вертикалі, робити між ними відступи і гнучко керувати розташуванням блоків.

Раніше для верстки часто використовували складніші підходи, а зараз Flexbox — це майже обов’язкова тема для будь-якого початківця у frontend.

8.1 Контейнер display: flex

Щоб Flexbox почав працювати, треба зробити батьківський елемент flex-контейнером.

.container { display: flex; }

Після цього всі прямі дочірні елементи стануть flex-елементами.

8.2 Розташування по горизонталі

За замовчуванням Flexbox ставить елементи в ряд.

.container { display: flex; gap: 20px; }

Тут gap створює відстань між елементами.

8.3 Вирівнювання

Через Flexbox дуже зручно вирівнювати елементи.

.container { display: flex; justify-content: center; align-items: center; }

Тут:
justify-content вирівнює елементи по головній осі
align-items вирівнює елементи по поперечній осі

8.4 Чому Flexbox важливий?

Flexbox дуже часто використовують для:
— меню
— карток товарів
— блоків курсів
— хедерів і футерів
— адаптивних секцій

.container { display: flex; justify-content: space-between; align-items: center; }

Саме через Flexbox можна швидко зробити акуратний сучасний макет без складних старих підходів.

Порада: якщо тобі треба швидко розкласти елементи в ряд або красиво їх вирівняти — дуже часто рішенням буде саме Flexbox.
Практика:
  • створи контейнер із трьома блоками;
  • розмісти їх у ряд через Flexbox;
  • додай відстань між ними;
  • вирівняй блоки по центру.

⚠ 9. Типові помилки новачків

  • Закрив не той тег або забув закрити елемент.
  • Переплутав HTML і CSS — структура має бути в HTML, оформлення в CSS.
  • Неправильний шлях до файлу у src або href.
  • Неправильно написаний селектор — наприклад, забув крапку перед класом.
  • Проблеми з відступами та Box Model — елементи стоять не там, де очікувалося.
  • Забув підключити CSS-файл.
<link rel="stylesheet" href="style.css">

Якщо цей рядок не підключений або шлях до файлу неправильний, сторінка буде без стилів.
