Щоб писати програми на C#, потрібне середовище розробки та платформа .NET. Найзручніший варіант для новачка на Windows — це Visual Studio Community.

⌨ 2. Структура програми та виведення

У C# будь-яка програма має певну структуру. Новачку важливо зрозуміти, що програма складається не просто з випадкових команд, а з логічних частин.

2.1 Простір імен using

Ключове слово using підключає готові можливості з бібліотек .NET. Наприклад, щоб працювати з консоллю, нам потрібен простір імен System.

2.2 Клас і метод Main

У C# код зазвичай знаходиться всередині класів. Точка входу в програму — це метод Main. Саме з нього починається виконання програми.

2.3 Виведення тексту

Для виведення тексту на екран використовується Console.WriteLine(). Це один із найперших інструментів, який вивчає кожен новачок.

using System; class Program { static void Main(string[] args) { Console.WriteLine("Привіт, Світ!"); } }

У цьому прикладі:
using System; — підключає можливості для роботи з консоллю
class Program — створює клас
static void Main(string[] args) — головний метод програми
Console.WriteLine() — виводить текст на екран

Запам’ятай: у C# все більш структуровано, ніж у деяких інших мовах. Це спочатку може виглядати складніше, але потім дуже допомагає.

🔧 3. Змінні та типи даних

Змінна — це іменоване місце в пам’яті, де зберігаються дані. У C# кожна змінна має чіткий тип, і це одна з сильних сторін мови, бо допомагає уникати багатьох помилок.

3.1 Основні типи даних

  • int — цілі числа
  • double — дробові числа з високою точністю
  • float — дробові числа меншої точності
  • char — один символ
  • bool — логічне значення: true або false
  • string — текст

3.2 Приклади створення змінних

int age = 18; double price = 199.99; char letter = 'A'; bool isStudent = true; string name = "Vitalik";

Тут ми одразу і створюємо змінну, і даємо їй значення. Це називається ініціалізація.

3.3 Ключове слово var

У C# можна використовувати var, коли компілятор сам може зрозуміти тип змінної з правої частини.

var count = 10; // int var message = "Hello"; // string var isDone = false; // bool

var не означає "будь-який тип". Тип все одно визначається, просто ти його явно не пишеш.

3.4 Константи

Якщо значення не повинно змінюватися, використовують const.

const double PI = 3.14159;
Практика:
  • створи змінні для імені, віку та міста;
  • створи константу для числа PI;
  • виведи всі значення на екран.

📊 4. Оператори: арифметичні, порівняння та логіка

Оператори — це спеціальні символи, які дозволяють виконувати дії над даними: рахувати, порівнювати і перевіряти умови.

4.1 Арифметичні оператори

Оператор Що робить Приклад
+ додавання 5 + 3
- віднімання 10 - 2
* множення 4 * 2
/ ділення 8 / 2
% остача від ділення 10 % 3
int x = 10; int y = 3; int sum = x + y; int diff = x - y; int prod = x * y; int quot = x / y; int rem = x % y;

4.2 Оператори порівняння

Оператори порівняння потрібні для того, щоб програма могла зіставляти значення і робити висновок: умова правильна чи ні. Результат такого порівняння завжди буде логічним значенням: true або false.

Саме оператори порівняння найчастіше використовуються в умовах if, циклах while, а також у складніших перевірках.

Оператор Що означає
== дорівнює
!= не дорівнює
> більше
< менше
>= більше або дорівнює
<= менше або дорівнює

Наприклад, якщо в програмі є змінна віку, ми можемо перевірити, чи користувач повнолітній:

int age = 18; Console.WriteLine(age == 18); // true Console.WriteLine(age != 20); // true Console.WriteLine(age > 16); // true Console.WriteLine(age < 10); // false Console.WriteLine(age >= 18); // true Console.WriteLine(age <= 17); // false

Тут програма по черзі порівнює значення age з іншими числами і повертає результат перевірки. Це не просто математика — це основа логіки в програмуванні.

Увага: не плутай = і ==. = — це присвоїти значення, == — це порівняти два значення.

4.3 Логічні оператори

Оператор Що робить
&& логічне "І"
|| логічне "АБО"
! логічне "НЕ"
int age = 20; bool hasMoney = true; bool canBuy = (age >= 18) && hasMoney;

У цьому прикладі змінна canBuy буде true тільки тоді, коли користувачу 18 або більше і в нього є гроші.

🔄 5. Керування потоком: умови та цикли

Керування потоком означає, що програма може не просто виконувати команди зверху вниз, а приймати рішення і повторювати дії. Саме завдяки цьому програма починає реагувати на умови, введення користувача та різні ситуації.

Без умов і циклів будь-яка програма була б дуже примітивною: вона б лише раз виконала кілька рядків коду і завершилась. А от умови дозволяють вибирати, що саме робити, а цикли — робити це багато разів.

5.1 Умовний оператор if, else if, else

Це основа логіки в C#. Програма перевіряє вираз у круглих дужках. Якщо результат true, виконується один блок коду. Якщо false — програма переходить до наступного варіанта.

if — якщо умова правильна
else if — якщо попередня умова не спрацювала, але ця правильна
else — якщо жодна умова не підійшла

int score = 85; if (score >= 90) { Console.WriteLine("Відмінно!"); } else if (score >= 70) { Console.WriteLine("Добре!"); } else { Console.WriteLine("Потрібно підтягнути знання."); }

У цьому прикладі програма перевіряє оцінку. Якщо вона 90 або більше — виводиться "Відмінно". Якщо не 90, але хоча б 70 — "Добре". Якщо нічого не підходить — виконується else.

5.2 Оператор switch

switch корисний тоді, коли одна змінна може мати кілька конкретних значень. Це більш чистий і зручний варіант, ніж писати багато if підряд.

switch перевіряє значення
case — можливий варіант
break — зупиняє виконання після знайденого варіанта
default — спрацьовує, якщо нічого не підійшло

int day = 2; switch (day) { case 1: Console.WriteLine("Понеділок"); break; case 2: Console.WriteLine("Вівторок"); break; default: Console.WriteLine("Інший день"); break; }

Тут змінна day має значення 2, тому програма виведе "Вівторок". break дуже важливий, бо без нього виконання могло б перейти далі в наступні case.

5.3 Цикл for

Цикл for використовують тоді, коли ти заздалегідь знаєш, скільки разів треба повторити дію. Наприклад: вивести числа від 1 до 10 або пройтись по елементах масиву.

У циклі for є три частини:

  • початок — створення лічильника
  • умова — доки цикл працює
  • крок — як змінюється лічильник після кожного повтору
for (int i = 1; i <= 5; i++) { Console.WriteLine($"Лічильник: {i}"); }

Тут i спочатку дорівнює 1, потім після кожного повтору збільшується на 1. Цикл працює, поки i <= 5.

5.4 Цикл while

while використовують тоді, коли кількість повторів наперед невідома. Він працює доти, доки умова залишається істинною.

Це називають циклом з передумовою, бо умова перевіряється до виконання коду.

int energy = 3; while (energy > 0) { Console.WriteLine($"Енергія: {energy}"); energy--; }

У цьому прикладі цикл буде працювати, поки енергія більша за 0. На кожному кроці вона зменшується, і коли стане 0 — цикл завершиться.

5.5 Цикл foreach

foreach — один із дуже зручних циклів у C#. Його використовують для проходу по всіх елементах масиву або колекції без ручного керування індексом.

string[] names = { "Іван", "Марія", "Олег" }; foreach (string name in names) { Console.WriteLine(name); }

Тут цикл по черзі бере кожен елемент із масиву names і кладе його в змінну name. Це зручно, коли не потрібно самому працювати з індексами.

Порада: якщо треба просто пройти всі елементи масиву — часто найзручніше використовувати саме foreach.
Практика:
  • перевірити, чи число парне;
  • вивести числа від 1 до 10;
  • вивести всі елементи масиву через foreach;
  • порахувати суму чисел від 1 до n.

💬 6. Рядки та робота з текстом

У реальних програмах дуже часто треба працювати не тільки з числами, а й із текстом: іменами, повідомленнями, паролями, назвами міст, описами та введенням користувача. Для цього в C# використовується тип string.

Рядок — це послідовність символів, яку програма сприймає як єдине текстове значення. Наприклад, ім’я користувача або ціле речення.

6.1 Створення рядка

Щоб створити текстову змінну, потрібно використати тип string і записати текст у подвійних лапках.

string name = "Vitalik";

Тут у змінній name зберігається текст Vitalik. На відміну від char, який зберігає лише один символ, string зберігає ціле слово або речення.

6.2 Конкатенація рядків

Конкатенація — це об’єднання рядків. У C# для цього можна використовувати оператор +.

string firstName = "Віталік"; string text = "Привіт, " + firstName; Console.WriteLine(text);

У результаті на екран буде виведено: Привіт, Віталік.

6.3 Інтерполяція рядків

У C# є дуже зручний спосіб вставляти змінні прямо всередину тексту — це інтерполяція рядків. Для цього перед рядком ставлять символ $.

string nameUser = "Віталік"; int ageUser = 18; Console.WriteLine($"Мене звати {nameUser}, мені {ageUser} років.");

Такий підхід виглядає набагато чистіше і зрозуміліше, ніж постійно з’єднувати текст через +.

6.4 Довжина рядка

Іноді програмі треба дізнатись, скільки символів є у слові чи фразі. Для цього використовується властивість Length.

string word = "programming"; Console.WriteLine(word.Length);

Програма виведе кількість символів у слові programming.

6.5 Зчитування тексту з клавіатури

Щоб користувач міг ввести текст у консоль, використовують Console.ReadLine(). Ця команда зчитує весь введений рядок.

string userName = Console.ReadLine(); Console.WriteLine($"Привіт, {userName}");

Після введення імені програма збереже його у змінну і виведе привітання.

Порада: у C# властивість довжини рядка пишеться як Length з великої літери, бо це властивість об’єкта.
Практика:
  • зчитати ім’я користувача і вивести привітання;
  • порахувати довжину введеного слова;
  • вивести повідомлення через інтерполяцію рядка.

🗃 7. Масиви та базові колекції

Масив — це набір кількох елементів одного типу, які зберігаються під одним ім’ям. Це зручно, коли треба працювати не з одним числом або словом, а з цілою групою значень.

Наприклад, якщо потрібно зберегти оцінки студента, список імен або кілька чисел, масив набагато зручніший, ніж окремі змінні.

7.1 Створення масиву

У C# масив записується через квадратні дужки після типу даних.

int[] nums = { 10, 20, 30, 40, 50 };

Тут створюється масив із п’яти цілих чисел. Усі елементи мають один тип — int.

7.2 Індекси елементів

Кожен елемент масиву має свій індекс. Важливо пам’ятати: індексація починається з 0, а не з 1.

Console.WriteLine(nums[0]); // 10 Console.WriteLine(nums[2]); // 30

Тобто:
nums[0] — перший елемент
nums[1] — другий
nums[2] — третій

7.3 Перебір масиву циклом

Щоб не звертатися до кожного елемента вручну, масив часто проходять циклом for.

for (int i = 0; i < nums.Length; i++) { Console.WriteLine(nums[i]); }

Тут:
i = 0 — починаємо з першого елемента
i < nums.Length — цикл працює, поки не дійдемо до кінця масиву
nums[i] — доступ до поточного елемента

7.4 Колекція List

Масиви зручні, коли кількість елементів відома заздалегідь. Але в реальних програмах часто буває так, що кількість елементів змінюється. Для цього в C# є колекція List.

using System.Collections.Generic; List students = new List(); students.Add("Іван"); students.Add("Марія"); students.Add("Олег"); foreach (string student in students) { Console.WriteLine(student); }

Тут ми створюємо список рядків, додаємо в нього імена через Add(), а потім виводимо всі елементи циклом foreach.

7.5 Чому List зручний?

List дозволяє динамічно додавати нові елементи, видаляти їх і працювати з даними гнучкіше, ніж масив. Саме тому в C# списки використовують дуже часто.

Увага: якщо звернутися до неіснуючого індексу, наприклад до nums[10] у маленькому масиві, програма видасть помилку.
Практика:
  • створи масив із 5 чисел;
  • виведи всі елементи циклом;
  • знайди суму елементів масиву;
  • створи List<string> зі списком імен.

📦 8. Методи: створення, параметри та повернення значення

Метод у C# — це окремий блок коду, який виконує певну задачу. По суті, це те саме, що функція в інших мовах програмування, але в C# методи належать класам.

Методи потрібні для того, щоб код не перетворювався на хаос. Якщо один і той самий шматок логіки треба виконати кілька разів — краще винести його в метод і викликати тоді, коли потрібно.

Навіщо потрібні методи?

  • ✅ не треба дублювати код
  • ✅ програма стає читабельнішою
  • ✅ легше знаходити та виправляти помилки
  • ✅ можна розбити велику задачу на менші частини

8.1 Метод без параметрів

Найпростіший варіант — метод, який не приймає жодних даних. Він просто виконує команди, коли його викликають.

using System; class Program { static void SayHi() { Console.WriteLine("Привіт з методу!"); } static void Main(string[] args) { SayHi(); } }

Тут:
SayHi() — назва методу
void означає, що метод нічого не повертає
static дозволяє викликати метод без створення об’єкта класу

8.2 Метод з параметрами

Параметри потрібні тоді, коли метод має працювати з різними значеннями. Наприклад, не просто щось виводити, а виконувати обчислення для будь-яких чисел.

static int Add(int a, int b) { return a + b; }

У цьому прикладі:
a і b — параметри
int перед назвою методу означає, що метод повертає ціле число
return повертає результат назад туди, де метод був викликаний

8.3 Виклик методу

Щоб використати метод, його треба викликати по імені та передати аргументи, якщо вони потрібні.

int result = Add(5, 7); Console.WriteLine(result);

Тут метод Add отримує два числа — 5 і 7 — та повертає їх суму. Результат зберігається в змінній result.

8.4 Перевантаження методів

У C# можна створювати кілька методів з однаковою назвою, якщо в них різні параметри. Це називається перевантаженням.

static int Sum(int a, int b) { return a + b; } static double Sum(double a, double b) { return a + b; }

Тепер метод Sum може працювати і з цілими, і з дробовими числами. Компілятор сам визначить, який саме варіант треба викликати.

Запам’ятай: методи — це один із головних способів зробити код чистим, повторно використовуваним і професійно організованим.
Практика:
  • створи метод для додавання двох чисел;
  • створи метод, який вітає користувача по імені;
  • створи метод для обчислення квадрата числа.

🧠 9. Основи ООП: класи, об'єкти та властивості

C# — це об'єктно-орієнтована мова програмування. Це означає, що програми часто будуються навколо класів та об'єктів. На початку це може звучати складно, але насправді ідея досить проста.

Уяви, що клас — це креслення або шаблон. А об'єкт — це вже конкретна річ, створена за цим шаблоном. Наприклад, клас Student — це опис того, яким має бути студент, а об’єкт — це вже конкретний студент із власним ім’ям і віком.

9.1 Що таке клас?

Клас описує, які дані та дії буде мати майбутній об’єкт.

class Student { public string Name { get; set; } public int Age { get; set; } }

У цьому прикладі клас Student має дві властивості:
Name — ім’я студента
Age — вік студента

9.2 Що таке об'єкт?

Об’єкт — це конкретний екземпляр класу. Тобто ми беремо шаблон і створюємо на його основі реальну сутність у програмі.

Student s1 = new Student(); s1.Name = "Віталік"; s1.Age = 18;

Тут:
new Student() — створення нового об’єкта
s1 — змінна, в якій зберігається цей об’єкт
потім ми задаємо значення його властивостей

9.3 Властивості

Властивості в C# — це зручний спосіб читати і змінювати дані об’єкта. Запис { get; set; } означає, що значення можна і отримати, і змінити.

Console.WriteLine(s1.Name); Console.WriteLine(s1.Age);

Тут ми просто звертаємося до властивостей об’єкта і виводимо їх на екран.

9.4 Метод усередині класу

Клас може не тільки зберігати дані, а й виконувати дії. Для цього в ньому створюють методи.

class Student { public string Name { get; set; } public int Age { get; set; } public void ShowInfo() { Console.WriteLine($"Ім'я: {Name}, Вік: {Age}"); } }

Тепер кожен об’єкт класу Student може сам вивести свою інформацію.

9.5 Виклик методу об’єкта

Student s1 = new Student(); s1.Name = "Віталік"; s1.Age = 18; s1.ShowInfo();

Коли ми викликаємо s1.ShowInfo(), об’єкт сам виконує метод і показує свої дані. Саме в цьому і є суть ООП: поєднати дані та поведінку в одному об’єкті.

Просте запам’ятовування:
клас — шаблон
об’єкт — конкретна створена сутність
властивості — дані об’єкта
методи — дії об’єкта
Практика:
  • створи клас Car з властивостями Brand і Year;
  • створи об’єкт цього класу;
  • додай метод для виведення інформації про автомобіль.

⚠ 10. Типові помилки новачків

  • Забутий ; — багато інструкцій у C# завершуються крапкою з комою.
  • Неправильні дужки — у C# важливо правильно відкривати і закривати { }.
  • Плутанина між = і == — перше присвоює, друге порівнює.
  • Невірний тип даних — наприклад, спроба записати текст у int.
  • Забув using — іноді потрібен простір імен, щоб клас був доступний.
  • Неправильне використання Console.ReadLine() — воно повертає текст, тому для числа треба перетворення.
string input = Console.ReadLine(); int age = int.Parse(input);

Тут ми зчитуємо текст із консолі і перетворюємо його в число через int.Parse().
