📂 1. Вступ: Як налаштувати все для роботи

Щоб почати працювати з Python, потрібно встановити саму мову та обрати редактор коду або середовище розробки. Для новачка найпоширеніші варіанти — VS Code або PyCharm.

Крок 1: Встановлення Python

1. Завантаження: встанови Python на комп’ютер.
2. Перевірка: після встановлення можна перевірити, чи все працює, через команду python --version або py --version.
3. Вибір редактора: для легкого старту підійде VS Code, а для більшого комфорту — PyCharm.
4. Перший файл: створи файл з розширенням .py, наприклад main.py.
Простими словами: ти пишеш код у файлі .py, потім запускаєш його через Python, і інтерпретатор виконує твої команди рядок за рядком.
Особливість Python: це інтерпретована мова. Це означає, що вона не компілюється наперед у класичному сенсі, як C++, а виконується інтерпретатором.

⌨ 2. Структура програми та функція print()

Python відомий тим, що його код виглядає просто і чисто. Для найпростішої програми не потрібно багато службових конструкцій — достатньо просто написати команду.

2.1 Перша програма

Для виведення тексту в Python використовується функція print().

print("Привіт, Світ!") print(5 + 3)

У цьому прикладі:
print("Привіт, Світ!") — виводить текст
print(5 + 3) — спочатку обчислює вираз, а потім показує результат

2.2 Коментарі

Коментарі потрібні для пояснення коду. Python їх не виконує.

# Це коментар print("Python легко читати")
Пам’ятай: Python дуже чутливий до відступів. Саме через відступи мова розуміє, який код належить до якого блоку.

🔧 3. Змінні та типи даних

Змінна — це ім’я, під яким зберігається певне значення. У Python змінні створюються дуже просто: достатньо написати ім’я змінної, знак = і значення.

3.1 Динамічна типізація

У Python не потрібно заздалегідь писати тип змінної. Мова сама визначає, що це за тип, коли ти присвоюєш значення.

name = "ДМТК" year = 2025 price = 199.99 is_student = True

Тут:
name — рядок
year — ціле число
price — дробове число
is_student — логічне значення

3.2 Основні типи даних

  • int — цілі числа
  • float — дробові числа
  • str — текст
  • bool — True або False

3.3 Виведення змінних

name = "Віталік" age = 18 print(name) print(age)

3.4 Перетворення типів

Іноді треба явно перетворити один тип в інший.

year = 2025 print("Рік: " + str(year))

Тут число перетворюється в текст через str(), щоб його можна було об’єднати з рядком.

Практика:
  • створи змінні для імені, віку та міста;
  • виведи їх на екран;
  • спробуй перетворити число в текст через str().

📊 4. Оператори: арифметичні, порівняння та логіка

Оператори дозволяють працювати зі значеннями: рахувати, порівнювати і перевіряти умови.

4.1 Арифметичні оператори

Оператор Що робить
+ додавання
- віднімання
* множення
/ ділення
// цілочисельне ділення
% остача від ділення
x = 10 y = 3 print(x + y) print(x - y) print(x * y) print(x / y) print(x // y) print(x % y)

4.2 Оператори порівняння

Ці оператори потрібні, щоб програма могла перевірити, правильна умова чи ні. Результатом завжди буде True або False.

Оператор Що означає
== дорівнює
!= не дорівнює
> більше
< менше
>= більше або дорівнює
<= менше або дорівнює
age = 18 print(age == 18) print(age != 20) print(age > 16) print(age < 10) print(age >= 18) print(age <= 17)

4.3 Логічні оператори

Оператор Що робить
and логічне "І"
or логічне "АБО"
not логічне "НЕ"
age = 20 has_money = True can_buy = (age >= 18) and has_money print(can_buy)

🔄 5. Керування потоком: умови

Керування потоком означає, що програма може приймати рішення. Саме завдяки цьому вона не просто виконує код зверху вниз, а вибирає, який блок запускати залежно від ситуації.

У Python для цього використовують:
if — якщо умова істинна
elif — інакше якщо попередня умова не підійшла
else — інакше, якщо нічого не спрацювало

5.1 Базовий приклад if / elif / else

score = 85 if score >= 90: print("Відмінно!") elif score >= 75: print("Добре!") else: print("Потрібно ще попрацювати.")

У цьому прикладі:
— якщо оцінка 90 або більше, виведеться "Відмінно!"
— якщо менше 90, але 75 або більше, виведеться "Добре!"
— якщо не підходить жоден варіант, спрацює else

5.2 Чому відступи тут критично важливі?

У Python немає фігурних дужок, як у C++ або C#. Саме відступи показують, який код належить до умови.

age = 18 if age >= 18: print("Доступ дозволено") print("Користувач повнолітній") print("Кінець програми")

Тут перші два рядки з відступом належать до блоку if. Останній рядок без відступу виконається завжди.

Пам’ятай: неправильний відступ у Python — це не просто негарний код, а реальна помилка або неправильна логіка програми.
Практика:
  • перевірити, чи людина повнолітня;
  • знайти більше з двох чисел;
  • перевірити, чи число парне чи непарне.

🔁 6. Цикли: for та while

Цикли потрібні для того, щоб повторювати одну й ту саму дію багато разів. Без циклів програмісту довелося б вручну писати однакові рядки коду знову і знову, а це незручно, довго і легко призводить до помилок.

У Python найчастіше використовують два основні цикли:
for — коли ми проходимо по послідовності або знаємо діапазон значень
while — коли треба повторювати дію, поки виконується певна умова

Цикли використовують у дуже багатьох задачах:
— вивести числа від 1 до 10
— знайти суму чисел
— обійти всі елементи списку
— повторювати дію, поки користувач не введе правильне значення

6.1 Цикл for

У Python цикл for дуже зручний і простий. Його часто використовують разом із range(), щоб пройти по числах у певному діапазоні.

for i in range(1, 6): print("Крок:", i)

Тут:
i — це змінна циклу
range(1, 6) створює послідовність від 1 до 5
число 6 не входить у діапазон

Тобто програма по черзі підставляє в i числа 1, 2, 3, 4, 5 і виконує тіло циклу на кожному кроці.

6.2 Цикл while

Цикл while працює доти, доки умова є істинною. Це корисно тоді, коли ми не знаємо наперед точну кількість повторів.

energy = 3 while energy > 0: print("Енергія:", energy) energy -= 1

У цьому прикладі цикл виконується, поки змінна energy більша за 0. Після кожного повтору ми зменшуємо її на 1. Коли вона стане 0, умова стане хибною і цикл завершиться.

6.3 Чим відрізняються for і while?

for зручний тоді, коли треба пройти по готовій послідовності або по діапазону чисел.
while зручний тоді, коли програма має повторювати дію до настання певної умови.

Наприклад:
— for: вивести числа від 1 до 10
— while: питати пароль, поки користувач не введе правильний

6.4 Вкладені цикли

Іноді один цикл можна вкладати в інший. Це називається вкладеними циклами. Так часто будують таблиці, матриці або працюють із двовимірними даними.

for i in range(1, 4): for j in range(1, 3): print(i, j)

Тут зовнішній цикл керує значенням i, а внутрішній — значенням j. Для кожного значення i внутрішній цикл проходить усі свої значення.

6.5 Чому цикли важливі?

Цикли — це одна з головних основ програмування. Вони потрібні майже всюди: у списках, задачах на математику, роботі з файлами, ботах, іграх та автоматизації.

Обережно: якщо умова в while ніколи не стане хибною, програма зациклиться і може працювати без кінця.
Практика:
  • вивести числа від 1 до 10;
  • порахувати суму чисел від 1 до n;
  • вивести таблицю множення для числа;
  • написати цикл, який рахує у зворотному порядку.

💬 7. Рядки та робота з текстом

У Python текст зберігається в типі str. Рядки потрібні майже в кожній програмі, тому що через них зберігаються імена користувачів, повідомлення, паролі, команди, назви файлів, тексти кнопок та багато іншого.

Простими словами, рядок — це послідовність символів, яку програма сприймає як одне текстове значення.

7.1 Створення рядка

Щоб створити рядок, достатньо записати текст у лапках.

name = "Віталік"

Тут змінна name зберігає текстове значення. У Python можна використовувати як подвійні, так і одинарні лапки.

7.2 Об’єднання рядків

Рядки можна об’єднувати через оператор +. Це корисно, коли ми хочемо скласти готове повідомлення з кількох частин.

first_name = "Віталік" text = "Привіт, " + first_name print(text)

У результаті програма виведе Привіт, Віталік.

7.3 f-рядки

У Python є дуже зручний спосіб вставляти змінні прямо всередину тексту — це f-рядки. Вони часто зручніші та читабельніші, ніж звичайне об’єднання через +.

name = "Віталік" age = 18 print(f"Мене звати {name}, мені {age} років.")

Тут змінні name і age підставляються прямо в рядок у фігурних дужках.

7.4 Довжина рядка

Іноді потрібно дізнатися, скільки символів містить слово або речення. Для цього використовується функція len().

word = "programming" print(len(word))

Програма виведе кількість символів у слові programming.

7.5 Доступ до окремих символів

У рядку можна звертатися до конкретного символу за індексом. У Python індексація починається з 0.

city = "Lviv" print(city[0]) print(city[1])

Тут:
city[0] — це перший символ
city[1] — другий символ

7.6 Введення тексту

Щоб користувач міг ввести рядок із клавіатури, використовують функцію input().

user_name = input("Введіть ваше ім'я: ") print(f"Привіт, {user_name}")

Тут програма спочатку показує запрошення до вводу, потім зберігає введений текст у змінну і використовує його далі.

Пам’ятай: усе, що повертає input(), у Python спочатку є текстом. Якщо користувач вводить число, а ти хочеш працювати саме з числом, його треба перетворити окремо.
Практика:
  • зчитати ім’я користувача;
  • вивести привітання;
  • порахувати довжину введеного слова;
  • вивести перший символ введеного тексту.

🗃 8. Списки та базові колекції

Список у Python — це структура даних, яка може зберігати багато елементів під одним ім’ям. Це одна з найважливіших і найуживаніших речей у Python.

Через списки можна зберігати:
— числа
— слова
— оцінки
— результати обчислень
— навіть інші списки

8.1 Створення списку

Список записується у квадратних дужках, а елементи відокремлюються комами.

numbers = [10, 20, 30, 40, 50]

Тут створено список із п’яти чисел.

8.2 Доступ до елементів

Щоб отримати конкретний елемент списку, треба вказати його індекс. У Python індексація починається з 0.

print(numbers[0]) print(numbers[2])

Тобто:
numbers[0] — перший елемент
numbers[1] — другий
numbers[2] — третій

8.3 Перебір списку

Список дуже зручно перебирати циклом for. Це один із найчастіших сценаріїв у Python.

for number in numbers: print(number)

На кожному кроці цикл бере черговий елемент списку і записує його в змінну number.

8.4 Додавання елемента

У списки можна додавати нові значення. Для цього часто використовують метод append().

numbers.append(60) print(numbers)

Після цього в кінець списку додається число 60.

8.5 Видалення елемента

Іноді потрібно не тільки додавати елементи, а й видаляти їх. Наприклад, можна видалити значення за допомогою remove().

numbers.remove(30) print(numbers)

Цей код прибере зі списку число 30.

8.6 Чому списки важливі?

Списки використовуються всюди: у задачах на оцінки, меню, товари, повідомлення, результати ігор, списки користувачів і ще в дуже багатьох речах. Без списків Python неможливо нормально уявити.

Увага: якщо звернутися до неіснуючого індексу, наприклад numbers[10], Python видасть помилку.
Практика:
  • створи список із 5 чисел;
  • виведи всі елементи;
  • знайди суму елементів;
  • додай нове число через append();
  • видали один елемент.

📦 9. Функції

Функція — це окремий блок коду, який виконує певну задачу. Функції потрібні для того, щоб не дублювати один і той самий код багато разів і робити програму більш зрозумілою.

Простими словами:
— якщо якийсь шматок коду повторюється, його краще винести у функцію
— функція може приймати дані
— функція може повертати результат

9.1 Функція без параметрів

Найпростіший варіант — функція, яка просто виконує певну дію, коли її викликають.

def say_hi(): print("Привіт з функції!") say_hi()

Тут:
def — ключове слово для створення функції
say_hi — назва функції
код із відступом — тіло функції

9.2 Функція з параметрами

Параметри дозволяють передавати у функцію значення, з якими вона має працювати.

def add(a, b): return a + b result = add(5, 7) print(result)

У цьому прикладі функція add отримує два числа і повертає їх суму.

9.3 Навіщо потрібен return?

return повертає результат роботи функції назад туди, де вона була викликана. Саме через це функція може не просто щось друкувати, а реально обчислювати значення і віддавати його далі програмі.

def square(x): return x * x print(square(4))

Тут функція повертає квадрат числа, а не просто друкує його всередині себе.

9.4 Чому функції важливі?

Функції дозволяють:
— не дублювати код
— робити програму чистішою
— розбивати велику задачу на маленькі частини
— повторно використовувати готову логіку

9.5 Локальні змінні

Змінні, створені всередині функції, живуть тільки всередині неї. Поза функцією вони недоступні. Це називається локальною областю видимості.

def test(): message = "Привіт" print(message) test()

Тут змінна message існує тільки всередині функції test().

Порада: хороша функція зазвичай виконує одну зрозумілу задачу. Не треба намагатися вмістити всю програму в одну велику функцію.
Практика:
  • створи функцію привітання;
  • створи функцію для додавання двох чисел;
  • створи функцію для знаходження квадрата числа;
  • створи функцію, яка приймає ім’я і вік та повертає готовий текст.

⚠ 10. Типові помилки новачків

  • Неправильні відступи — у Python вони критично важливі.
  • Плутанина між = і == — перше присвоює, друге порівнює.
  • Спроба об’єднати рядок і число без перетворення.
  • Невірний індекс списку.
  • Нескінченний цикл у while.
  • Забув двокрапку після if, for, while, def.
age = 18 print("Мені " + str(age) + " років")

Тут число спочатку перетворюється в текст через str(), і тільки тоді об’єднується з рядком.

  3. Знайди найбільший елемент.
